# 10｜视觉证据修正认知先验：完整方案

日期：2026-08-20

本文件保留09号文件对当前OnlineFusion的NO-GO判断，但取代其中“小规模Ghost Probe优先”的建议：后续直接实现并完整训练本文方案。

## 1. 核心判断

已知结果：

- 静态 LLM-Grid + Try5 单向 attention：SR **65.42**，SPL **55.25**；
- GT 认知地图 + 同类单向 attention：SR 约 **72**。

这证明认知地图质量确实能转化为导航收益，约有6.6个SR点的空间。因此不再修改决策主干，直接围绕下面一条因果链设计完整模型：

```text
视觉证据修正已观察区域的具体错误
        → 根据已确认内容修订未见区域
        → 仍正确的未见先验保持不变
        → 原Try5单向attention读取更新地图并决策
```

## 2. 基本结构

保留原有语言、RGB、Depth、panorama、视觉拓扑图、Map Encoder、global encoder和动作head。废弃当前 OnlineFusion 的整图token重写、progress/recovery/ghost residual，只新增一个地图后端：

```text
静态LLM先验 P0（永不覆盖）
           │
当前12-view RGB-D → 空间视觉证据 → 累积证据 Et、覆盖 Ct
           │                         │
           └────────→ PosteriorRefiner
                                │
                         更新认知地图 Pt
                                │
                   原Map Encoder + Try5单向attention
                                │
                         原导航决策主干
```

`P0` 始终保留，`Pt` 是当前时刻供导航使用的后验地图。episode结束后清空 `Et/Ct/Pt`。

## 3. 空间视觉证据

### 3.1 当前缓存不够

现有 `panorama_semantics_v1.hdf5` 每个viewpoint只有一个 `(37,)` panorama类别集合，不包含类别的朝向和距离，无法判断应修正哪个网格位置。

完整方案需要生成 `v2` 缓存：

```text
每个viewpoint：12个不重叠的30°方位段 × 37类 × 5个深度段
深度段：0–2、2–4、4–6、6–8、8–10 m
另存由Depth逐射线计算的有效可见区域
```

Habitat缓存生成时已有12路Semantic+Depth，因此只改变标签聚合方式，不改变训练数据或前端encoder。

### 3.2 VisualEvidenceHead

在现有12个panorama view embedding后增加一个共享head，逐方向预测：

- 37类在5个距离段中的存在概率；
- 每个预测的置信度。

预训练用v2缓存监督；预训练结束后冻结。DAgger/推理只使用head预测，不读取Semantic GT，也不会增加每个连续动作的语义标注成本。

### 3.3 写入地图坐标

只在ETP产生高层决策的key waypoint更新，不在每个连续forward/turn动作更新。

利用已知的episode起点、初始heading、当前agent pose和0.5 m网格尺寸，把12方向×5距离段投影到以起点为基准的地图坐标：

```text
当前相对位移 + 当前朝向 + 视角方位 + 深度段
                    → 100×100 evidence grid
```

LLM预测位置可以不准；视觉证据仍写到它在真实轨迹中的位置。某个LLM实体若被放错，只在其错误位置真正被观察并否定后删除，不能因为别处没看到就删除。

## 4. 地图如何更新

### 4.1 三种状态必须分开

每个格子分别记录：

- `prior`：LLM预测；
- `observed-positive/negative`：有有效视野支持或否定；
- `unknown`：尚未观察，不能当作负例。

视觉证据按置信度累积为 `Et`，有效深度投影累积为覆盖 `Ct`。相同位置被多次观察时做置信度加权平均，不重复增加实体。

### 4.2 已观察区域：直接纠错

对 `Ct>0` 的格子：

```text
ObservedPosterior = (1-q)·P0 + q·Et
```

`q` 来自视觉置信度和重复观测一致性：

- 视觉发现LLM遗漏的类别：补入；
- 视觉与LLM一致：提高置信度；
- 格子被Depth射线真实覆盖且高置信视觉否定LLM类别：抑制；
- 没有有效覆盖：绝不形成负证据。

### 4.3 未观察区域：有依据地修订

使用一个小型卷积编码器-解码器 `PosteriorRefiner`，输入：

```text
P0、上一步Pt-1、Et、Ct、instruction pooled feature
```

输出未观察区域的残差 `Δt` 和写门 `βt`：

```text
UnseenPosterior = P0 + βt·Δt
Pt = Ct·ObservedPosterior + (1-Ct)·UnseenPosterior
```

这里有三个硬约束：

1. `P0` 永远不被修改，随时可作为保底；
2. `βt·Δt` 只能作用于未观察区域；
3. 无新视觉证据时强制 `βt=0`，地图退化为原始先验。

因此已观察区域由证据接管，未观察区域默认保持原先验；只有当已观察内容为远端修订提供了依据时，才允许改变未见区域。

## 5. 如何监督“改错”和“保留”

对每个expert prefix都直接计算地图监督，不再只监督最终prefix。GT只作为训练target，不进入模型输入。

### 5.1 损失

1. `L_visual`：12方向×37类×5距离段的BCE；仅预训练，之后冻结head。
2. `L_seen`：更新地图与认知地图GT在已覆盖区域的Focal BCE + Dice，监督具体纠错。
3. `L_fix`：在未观察区域中，只对 `P0` 与GT发生冲突的有效语义support监督，训练远端修订。
4. `L_keep`：在未观察区域中，对 `P0` 与GT一致的正语义格子保持原值；全零背景仍视为unknown，不纳入保留监督。
5. `L_shuffle`：把视觉证据换成其他episode后，强制未见残差接近0，防止网络仅凭额外类别或scene inventory随意改图。
6. `L_SAP/L_action`：保留原预训练SAP和DAgger action CE，使地图修改最终服务于导航。

总目标可从以下权重开始：

```text
L = L_base
  + 0.30 L_seen
  + 0.20 L_fix
  + 0.10 L_keep
  + 0.05 L_shuffle
  + 0.20 L_visual       # 仅预训练
```

不再加入progress、recovery、ghost residual和无GT的state loss，避免再次把核心因果问题与其他辅助任务混在一起。

## 6. 训练Pipeline

### 6.1 预训练

1. 从完整LLM-Grid Try5预训练权重初始化，保留原单向attention结构；
2. expert trajectory按prefix展开；每个prefix只消费截至当前的视觉证据；
3. VisualEvidenceHead产生空间证据，更新 `Et/Ct/Pt`；
4. 每个prefix计算 `L_seen/L_fix/L_keep/L_shuffle`；
5. `Pt`经原Map Encoder和Try5单向attention进入MLM/SAP主干；
6. 前端encoder冻结；VisualEvidenceHead和PosteriorRefiner用 `1× LR`，Map Encoder、Try5 attention及导航后端用 `0.1× LR`。

### 6.2 DAgger

1. VisualEvidenceHead冻结，关闭 `L_visual`；
2. 每个高层key waypoint用当前12-view RGB-D预测新证据；
3. 用真实agent pose投影并递归更新 `Pt`；
4. 原Try5单向attention读取 `Pt`，原action head选择STOP/visited/ghost；
5. 训练 `L_action + L_seen + L_fix + L_keep + L_shuffle`；
6. PosteriorRefiner用 `1× LR`，Map Encoder、Try5 attention和原导航后端用 `0.1× LR`，所有前端保持冻结。

推理时不使用GT地图、Semantic sensor或在线LLM，只增加一个轻量视觉证据head、一个100×100地图更新器和一次Map Encoder前向。

## 7. 最终实验与成败标准

直接按与Try5相同的完整预训练、DAgger预算和固定评测协议训练本方案，不先做小型probe。比较：

```text
Try5静态LLM地图：SR 65.42 / SPL 55.25
完整Posterior方案：待训练
GT认知地图上界：SR约72
```

主目标不是地图loss下降，而是完整方案同时满足：

- 固定endpoint的SR、SPL均超过Try5；
- SR至少达到约 **67.6**，即收回LLM→GT上界差距的三分之一；
- observed区域地图质量持续提高；
- unobserved正确先验保留率不下降；
- shuffled evidence不能产生同等收益。

若完整预算仍不能超过Try5，则直接否定“视觉证据在线修正认知地图可提升导航”这一实现方向；只有达到上述目标后，再做模块消融。

## 8. 一句话总结

**不再让拓扑节点无坐标地重写地图token；把视觉证据先投影为有覆盖范围的空间证据，明确修正已见区域，再受约束地修订未见区域，最后完全交回已验证的Try5单向attention做导航。**
