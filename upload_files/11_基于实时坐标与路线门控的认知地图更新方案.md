# 11｜基于实时坐标与路线门控的认知地图更新方案

日期：2026-08-20

本文取代10号方案，作为下一版实现依据。核心变化是：**不按teacher/student身份决定是否更新，而按当前观测是否属于剩余路线决定。**

## 1. 核心目标

```text
静态LLM-Grid先验 P0
        +
当前高层step的空间视觉证据
        ↓
属于剩余路线：修正已见区域，并受约束地修订未见区域
偏离剩余路线：认知地图不更新，观测只保存在视觉拓扑图
        ↓
原Try5单向attention读取当前认知地图并决策
```

依据：静态LLM-Grid Try5为 SR 65.42 / SPL 55.25，GT认知地图单向attention约为 SR 72，说明提高地图质量具有明确导航上界。

## 2. 为什么不能只按teacher-forcing更新

teacher/student只表示动作来源，不等于观测是否属于认知地图：

- student动作也可能仍在正确路线附近；
- teacher动作处看到的部分物体也可能与剩余指令无关；
- 测试阶段没有teacher标记，若student一律不更新，在线更新会退化为静态Try5。

正确标准应是 `route_relevant`：当前位置是否位于当前进度之后的GT路线带内，并与剩余指令相容。

训练时用GT路线生成标签；测试时由模型预测，不使用GT。

## 3. 测试阶段可用的坐标

每个高层step均可从Habitat Simulator实时获取：

```text
agent position = (x, y, z)
agent rotation / heading
```

当前代码已将visited waypoint真实坐标保存到 `GraphMap.node_pos`；ghost坐标由当前pose、候选方向和距离估计。因此坐标不是新增传感器，而是现有ETP定位与拓扑建图的一部分。

episode开始时保存：

- 世界坐标起点 `(x0,z0)` 和初始朝向 `h0`；
- 认知地图中的起点格子 `(r0,c0)`；
- 网格尺寸 `0.5 m/cell`。

当前waypoint和视觉证据统一转为起点相对坐标，再写入认知网格。坐标轴、正负号和旋转必须复用仓库已有坐标工具，并用起点、前进1 m、左转/右转三个固定样例做单测。

## 4. 网络结构

### 4.1 保留部分

完全保留：

- language/RGB/Depth encoder；
- panorama encoder和waypoint predictor；
- ETP视觉拓扑图；
- Map Encoder；
- Try5 map→graph单向attention；
- global encoder和原动作head。

废弃当前OnlineFusion的整图token重写、progress/recovery/ghost residual。新增三个直接模块。

### 4.2 模块一：SpatialVisualHead

现有v1缓存每个viewpoint只有 `(37,)` 类别集合，不能定位物体。重新生成v2缓存：

```text
12个30°方位段 × 37类 × 5个距离段
距离段：0–2、2–4、4–6、6–8、8–10 m
+ Depth射线覆盖mask
```

`SpatialVisualHead`读取现有12-view RGB/Depth表示，输出相同结构和置信度。预训练后冻结；DAgger/测试不读取Semantic GT。

### 4.3 模块二：RouteUpdateGate

输入：

```text
instruction pooled feature
+ 当前panorama feature
+ 当前地图context
+ 当前节点/历史拓扑表示
```

输出 `g_t∈[0,1]`：当前观测是否属于“尚未完成的路线部分”。

训练标签：

- 当前点距GT路线的当前进度及其后缀 `≤3 m`：正例；
- 只靠近已经完成的旧路段，或距整个后缀 `>3 m`：负例。

因此student rollout仍在正确路线时可以更新；真正偏航或倒退到旧路段时禁止污染认知地图。

### 4.4 模块三：PosteriorRefiner

维护四个episode状态：

- `P0`：原始LLM先验，永远不覆盖；
- `Pt`：当前供导航使用的认知地图；
- `Et`：累计空间视觉证据；
- `Ct`：累计有效视觉覆盖。

每个高层step先把方位×距离证据结合实时pose投影到 `100×100` 网格。

若路线门关闭：

```text
Pt = Pt-1
```

该观测只进入原视觉拓扑图，不进入认知地图。

若路线门开启，已观察区域按视觉置信度纠错：

```text
ObservedPosterior = (1-q)·Pt-1 + q·Et
```

未观察区域由轻量卷积编码器-解码器输出残差 `Δt` 和写门 `βt`：

```text
UnseenPosterior = P0 + βt·Δt
Pt = Ct·ObservedPosterior + (1-Ct)·UnseenPosterior
```

硬约束：

1. `P0`始终保留；
2. 没有新证据或 `g_t=0` 时，未见残差为0；
3. 未被Depth真实覆盖的区域不能产生视觉负证据；
4. 全零格子视为unknown，不视为物体不存在。

## 5. 从Depth观测到地图格子

当前pose已知后，空间投影为：

```text
方位段 + 距离段
→ 当前相机坐标中的局部位置
→ 结合当前position/heading转为世界坐标
→ 减去episode起点并转到认知地图轴
→ 除以0.5 m并加(r0,c0)
```

Depth本身只有几何距离，没有类别；类别来自 `SpatialVisualHead`。因此v2空间语义head是必要条件，不能仅凭当前 `(37,)` head和Depth恢复类别位置。

## 6. 损失

保留原 `MLM/SAP/action CE`，新增：

1. `L_visual`：方位×类别×距离的BCE；仅预训练。
2. `L_gate`：路线门的class-balanced BCE；主要由DAgger的on/off-route样本训练。
3. `L_seen`：已覆盖区域的Focal BCE + Dice，监督具体视觉纠错。
4. `L_fix`：未见区域中 `P0` 与GT冲突的有效语义support，监督远端修订。
5. `L_keep`：未见区域中 `P0` 与GT一致的正语义格子保持不变。
6. `L_shuffle`：换成其他episode视觉证据时，强制未见残差为0。

建议初始权重：

```text
L = L_base
  + 0.20 L_visual       # 仅预训练
  + 0.10 L_gate
  + 0.30 L_seen
  + 0.20 L_fix
  + 0.10 L_keep
  + 0.05 L_shuffle
```

每个expert/student prefix都直接计算有效损失，不只监督episode最后一步。

## 7. 训练Pipeline

### 7.1 预训练

1. 从完整LLM-Grid Try5预训练权重初始化；
2. expert prefix均视为路线相关，训练SpatialVisualHead和PosteriorRefiner；
3. 从同scene但远离GT路线后缀的viewpoint采样负例，预训练RouteUpdateGate；
4. 每个prefix更新 `Et/Ct/Pt`，再由原Try5读取 `Pt` 完成MLM/SAP；
5. 前端encoder冻结；三个新模块用 `1× LR`，Map Encoder、Try5 attention和导航后端用 `0.1× LR`。

### 7.2 DAgger

每个高层step，无论动作来自teacher还是student，都执行：

```text
获取实时pose
→ SpatialVisualHead预测空间证据
→ RouteUpdateGate预测g_t
→ g_t高：更新认知地图
→ g_t低：保持Pt不变
→ 原Try5读取Pt并产生下一动作
```

- SpatialVisualHead冻结；
- RouteUpdateGate、PosteriorRefiner用 `1× LR`；
- Map Encoder、Try5 attention和导航后端用 `0.1× LR`；
- 前端encoder保持冻结；
- `L_gate`使用GT后缀路线标签，但地图更新使用模型预测的软门，保持训练/测试一致。

### 7.3 测试

测试阶段每个高层step同样读取实时agent坐标和朝向，但不使用GT路线、Semantic sensor或teacher action：

```text
实时pose + RGB-D
→ 预测空间证据和路线门
→ 条件更新Pt
→ 原Try5单向attention决策
```

## 8. 成败标准

直接进行完整预训练和DAgger，固定endpoint与Try5比较：

- 必须同时超过 SR 65.42、SPL 55.25；
- SR目标至少约67.6，即收回LLM地图到GT地图上界差距的三分之一；
- on-route observed地图质量提高；
- off-route期间未见地图变化接近0；
- unobserved正确先验保留率不下降；
- shuffled evidence不能得到相同收益。

完整预算仍不能超过Try5，则停止该方向；达到目标后再做消融。

## 9. 一句话总结

**测试时已有实时waypoint坐标，因此可以做空间视觉投影；是否更新认知地图不看teacher/student，而看观测是否属于剩余路线——相关观测修图，偏航观测只留在视觉拓扑图，最终仍由原Try5单向attention决策。**
