# 认知网格与视觉拓扑地图联合演化方案

方案日期：2026-08-12

目标基线：ETP-R1 + LLM-Grid

建议架构名：`mpsh`（Multi-hypothesis Posterior-Successor Handshake，多假设后验—后继握手网络）

## 0. 方案定位

本方案的首个主实验即采用最终形态，同时启用：

1. 多假设认知地图—世界坐标配准；
2. 视觉证据驱动的持久化认知地图后验；
3. 视觉拓扑边对认知地图可达性的在线校正；
4. 双尺度、双时标后继算子；
5. 路线阶段与 episode 进程建模；
6. 面向 ghost 节点的反事实长时程价值计算；
7. 完整地图解码与导航联合训练。

训练可以采用课程式优化和不同学习率，但所有模块从完整架构训练开始就存在，并在首个主实验中全部启用。确认完整系统有效后，再进行细致消融。

核心观点是：

> 视觉拓扑图不应只与认知地图做一次 attention，而应持续校正“哪里有什么、地图如何对齐、哪些转移真实可行”；认知地图也不应只提供静态 token，而应把校正后的远期语义与路径价值返回给真实 ghost 候选。

整体闭环如下：

```text
指令生成的认知网格先验
          ↓
多假设空间配准 + 认知事件链
          ↓
粒子化语义后验 + 指令转移先验
          ↑                    │
新 visited 视觉证据 ───────────┤
真实拓扑边/失败转移 ────────────┤
                               ↓
双尺度后继算子 + 路线进程状态
                               ↓
每个 ghost 的反事实长时程回报
                               ↓
ETP-R1 的 STOP / ghost 决策
```

## 1. 两种地图的职责与因果边界

### 1.1 信息权限

| 信息 | 权威来源 | 最终作用 |
|---|---|---|
| 已访问位置、真实拓扑边 | 视觉拓扑图 | 决定已验证可达性 |
| ghost 候选集合 | ETP-R1 视觉拓扑图 | 决定可执行动作空间 |
| 远处物体、区域、路线形状 | LLM 认知网格 | 提供长时程语义和路线先验 |
| 已观察区域语义 | 当前/历史视觉观测 | 支持、修正或否定认知先验 |
| 未观察区域语义 | 认知网格 | 作为带不确定性的想象保留 |
| 最终动作价值 | 两图联合 | 图保证可执行，认知后继状态提供远期价值 |

### 1.2 不可违反的规则

1. 只有真实执行后产生的新 visited 观测可以写语义后验。
2. 只有真实执行成功的拓扑边可以增加“可达”证据；可靠的失败执行才可增加“不可达”证据。
3. ghost 只参与反事实评分，绝不修改地图、配准粒子或可达性统计。
4. STOP 不产生空间写入。
5. 同一节点的同一视角只能写一次；重访只有获得新视角/新覆盖时才能增量写入。
6. 认知地图 GT、专家路径、场景语义和未来观测只用于构造训练 target，绝不进入推理 forward。
7. episode reset、并行环境 pause/reorder 时，图状态、地图状态和配准状态必须同步重置或重排。

## 2. 张量、坐标与持久化状态

### 2.1 已有输入

| 名称 | 形状 | 内容 |
|---|---:|---|
| `M0` | `(B,37,100,100)` | LLM-Grid 缓存中的初始语义先验 |
| `D_route` | `(B,5,2)` | 五段路线方向向量 |
| `start_position` | `(B,2)` | 缓存中的 level-local 起点位置 |
| `G_t` | `(B,N,768)` | 当前视觉拓扑节点表示 |
| `P_node` | `(B,N,2)` | 节点 world/level-local `(x,z)` 坐标 |
| `T_node` | `(B,N)` | STOP、visited、ghost 类型 |
| `V_t` | `(B,V,768)` | 当前新增 panorama 的视觉/深度特征 |
| `I` | `(B,L,768)` | 指令 token 表示 |

认知网格为 27 个物体通道 + 10 个区域通道，覆盖 `50 m × 50 m`，原始分辨率 `0.5 m/格`。现有 MapEncoder 下采样到 `10×10`，故单个现有空间 token 约覆盖 `5 m × 5 m`。

### 2.2 最终模型的三层空间尺度

| 层级 | 分辨率 | 职责 |
|---|---:|---|
| 原始语义层 | `100×100`，0.5 m/格 | 语义后验、覆盖、冲突与完整地图解码 |
| 局部转移层 | `20×20`，2.5 m/格 | 吸收拓扑边、表示中程可达性与局部绕行 |
| 全局转移层 | `10×10`，5 m/格 | 长程路线流、后继语义传播与全局 ghost 价值 |

最终架构固定采用 `20×20 + 10×10` 双尺度算子，不把 20×20 仅作为后续备选。

### 2.3 每个 episode 的完整状态

维护 `K=4` 个空间配准假设。第 `k` 个假设的状态为：

```text
S_t^k = {
  W_t^k, π_t^k, A_align,t^k,
  α_sem,t^k, β_sem,t^k, O_t^k, C_t^k,
  A+_local,t^k, A-_local,t^k, B_local,t^k,
  A+_global,t^k, A-_global,t^k, B_global,t^k,
  Φ_local,t^k, Φ_global,t^k, Ψ_local,t^k, Ψ_global,t^k,
  p_phase,t^k
}
```

其中：

- `W_t^k`：起点锚定的有界空间 warp；
- `π_t^k`：该配准假设的后验概率；
- `A_align,t^k`：增量事件对齐的前向消息；
- `α_sem/β_sem`：37 类原始网格的 Beta 语义后验；
- `O_t`：真实视觉覆盖度；
- `C_t`：认知先验与视觉证据冲突度；
- `A+/A-`：八方向转移的可达/不可达证据；
- `B`：与物理可达性分离的“指令路线偏好”；
- `Φ`：当前语义、进程、置信度的紧凑状态特征；
- `Ψ`：Bellman 迭代得到的后继特征；
- `p_phase`：路线阶段、偏航和结束状态分布。

另维护已消费观测集合 `E_seen` 与已消费真实边集合 `E_edge`，保证每条证据只进入状态一次。

### 2.4 坐标契约

统一实现唯一的 `world_xz_to_grid_rc()` 与逆变换。对当前 LLM-Grid cache，推荐显式使用：

```text
grid_cell = cached_start_level_m / 0.5
          + (node_world_xz - runtime_start_world_xz) / 0.5
```

坐标对象必须携带 `frame` 与 `unit`，禁止把 path5 的 grid-cell `start_position` 与 LLM-Grid 的 level-local meter `start_position` 混用。起点、四个单位方向、轴符号、旋转和边界裁剪需要单测。该架构明确启用坐标融合，因此需新增 ADR supersede ADR-0011；同时以新架构名注册，不能改变 ADR-0013 中 Try5 的既有含义。

## 3. 完整网络结构

### 3.1 指令认知先验编码器

输入 LLM 生成的 `M0`、方向向量、起点方向和 metadata：

```text
M0
 ├─ 1×1 semantic projection（继承现有 CLIP 初始化）
 ├─ 100×100 dense semantic features
 ├─ 20×20 local lattice tokens
 └─ 10×10 global lattice tokens + metadata token
```

两个 lattice 都加入连续 2D Fourier 坐标、到预测路线折线的距离、路线切向、起点相对位移和类别置信度。模型同时预测五段方向的显式有效 mask；不能用 `(0,0)` 判断 padding，因为原点本身可能合法。

### 3.2 从认知网格抽取事件链

不要求 LLM 额外输出严格有序 JSON。直接从预测网格和有效路线折线抽取 `P=16～24` 个认知事件：

```text
L_prior = {(l_p, q_p, s_p, u_p)}
```

- `l_p`：附近物体、区域和边界的联合语义；
- `q_p`：认知地图规范坐标；
- `s_p∈[0,1]`：沿预测路线的归一化顺序；
- `u_p`：该事件的不确定度。

连续重复或空事件合并；路线转折、区域边界和显著目标强制保留。该事件链承担“语义顺序可能正确、绝对几何可能错误”的中间表示。

### 3.3 视觉证据与视觉事件编码器

输入当前新增 panorama 的语言融合前 RGB/Depth 特征，避免将指令想象误判为视觉支持：

```text
多视角 RGB/Depth 特征
    → view-level Transformer
    → 几何感知注意力池化
    ├─ 37 类语义 evidence logits
    ├─ 37 类 visibility / valid-negative logits
    ├─ 物体与区域空间 footprint
    ├─ 证据 precision 与 aleatoric uncertainty
    └─ 视觉事件 embedding（物体、区域、边界、朝向）
```

深度用于推断可见范围与遮挡，视觉语义仍由网络预测；验证/测试时绝不读取 simulator semantic sensor。输出构成严格按 visited 顺序增长的视觉事件序列 `L_vis,t={y_1,...,y_t}`。

### 3.4 多假设空间配准器

固定维护 `K=4` 个粒子。每个 warp 包含：

- 起点锚定的平移残差、旋转和尺度；
- 4～6 个沿路线控制点的平滑偏移；
- 禁止镜像；
- 有界 Jacobian、弯曲与尺度正则。

对视觉事件 `j` 和认知事件 `p`，第 `k` 个粒子的匹配能量为：

```text
E_jp^k = w_s·semantic_similarity(y_j,l_p)
       - w_g·mahalanobis(x_j, W_k(q_p))
       - w_o·|τ_j-s_p|
       + w_e·edge_consistency(j,p)
       + w_b·boundary_consistency(j,p)
```

使用带 null/gap 状态的增量 soft-DTW/前向动态规划，允许指令遗漏实体、视觉漏检和重复地标。每次只加入新事件的预测似然：

```text
π_t^k ∝ π_{t-1}^k · exp(Δℓ_t^k / T)
```

粒子保持熵下限，避免一把椅子或一扇门导致过早坍缩。warp 由置信匹配通过可微 Procrustes/Gauss-Newton 更新。ghost 不能参与 `π_t^k` 或 warp 更新。

### 3.5 粒子化认知地图后验更新

将当前视觉 evidence 按每个 `W_t^k` 逆投影到认知规范坐标，在原始 `100×100` 网格做局部 evidential update。

初始值：

```text
α_sem,0^k = 1 + κ_LLM · M0
β_sem,0^k = 1 + κ_LLM · (1-M0)
```

对类别 `c`、网格 `r`：

```text
w_t^k(c,r) = visibility × precision × new_coverage
             × spatial_footprint × alignment_confidence

d_t^k(c,r) = strong_visible_conflict(M_{t-1}^k, evidence_t)

α'_t = 1 + (1-d_t)·(α_{t-1}-1)
β'_t = 1 + (1-d_t)·(β_{t-1}-1)

α_t = α'_t + w_t·evidence_t
β_t = β'_t + w_t·(1-evidence_t)
```

后验均值与不确定性为：

```text
M_t^k = α_t^k / (α_t^k + β_t^k)
U_t^k = Var[Beta(α_t^k, β_t^k)]
```

write footprint 外严格保持上一时刻状态。冲突折扣先降低过度自信，再吸收新证据，避免简单 Beta 累计在强冲突下仍越来越自信。

由 `M0、M_t、O_t、U_t、C_t` 显式导出四类 provenance：

1. 未核验想象：LLM 预测、但尚无视觉覆盖；
2. 视觉支持：覆盖充分且观测与先验一致；
3. 高置信冲突：真正可观测且多次证据反对先验；
4. 视觉新增：先验未预测、视觉持续观察到。

“没有检测到”只有在 visibility 与覆盖充分时才是负证据，否则仍为 unknown。

每个粒子解码完整世界坐标地图：

```text
M_world,t^k = Warp(M_t^k, W_t^k)
M_world,t   = Σ_k π_t^k M_world,t^k
```

训练和可视化使用 world-frame marginal；动作评分保留逐粒子结果，不能只从可能被平均模糊的地图决策。

### 3.6 双尺度、双时标转移算子

对每个粒子的 `20×20` 局部层和 `10×10` 全局层，分别预测八方向独立可达性 Beta 证据、路线偏好和语义状态：

```text
A+_s, A-_s ∈ R^(N_s×8)
B_s         ∈ R^(N_s×8)
Φ_s         ∈ R^(N_s×128)
s ∈ {local, global}
```

物理可达性和指令偏好必须分开：

```text
F_s(i,k) = A+_s(i,k) / (A+_s(i,k)+A-_s(i,k))
P_s(i,k) = Normalize_k(F_s(i,k) · exp(B_s(i,k)/T))
```

- `F` 回答“这个方向是否可能通行”；
- `B` 回答“这个方向是否符合当前指令路线”；
- 真实走过一条回退边会提高 `F`，但不会自动提高其路线偏好 `B`。

图节点通过坐标约束的 top-4 双线性/Gaussian 权重绑定到 lattice。STOP 的绑定行全为零。真实边首先累积为 micro-edge；只有累计轨迹跨出 `20×20` 的 cell 时，才写入一个 local exit，防止把一次约 1 m 的 ETP 动作误当成一次 2.5 m/5 m Bellman 转移。局部转移再聚合至 `10×10` 全局层。

成功执行边更新 `A+`；只有可靠碰撞/失败信号才更新 `A-`。ghost 转移仅作为临时反事实，不写 `A+/-`。

视觉语义创新、预测进程和转移 prediction error 同时更新 `Φ` 与局部 `B`；远端无证据区域保持 LLM 的低置信路线流。

双时标体现在：真实边到来时快速更新 feasibility；只有出现新视觉事件、阶段切换或持续冲突时才更新较稳定的语义后验与 route-flow。这样能快速学习“这条边确实可走”，又不会把一次偏航立即改写成新的指令路线。

### 3.7 路线阶段与 episode 进程头

路线进程同时从两条通路估计：

1. 事件对齐通路：soft-DTW 的认知事件后验给出沿路线的进度；
2. 神经通路：指令、visited 图、当前节点、后验地图和方向向量做 cross-attention。

两者融合输出：

```text
p_phase ∈ {phase_1,...,phase_5, off_route, finished}
remaining ∈ [0,1]
progress_uncertainty ∈ [0,1]
```

它不是仅供可视化的辅助头，而是完整决策状态的一部分：

- 调整局部/全局路线流 `B_t`；
- 指定下一批认知事件；
- 条件化后继语义 `Φ_t`；
- 进入 ghost 价值与 STOP head。

模型 forward 只能使用预测进程；GT 进程仅监督该预测。

### 3.8 双尺度后继特征求解器

在两个尺度上进行可微 Bellman 迭代：

```text
Ψ_s^(0) = Φ_s
Ψ_s^(h+1)(i) = Φ_s(i)
             + γ_s Σ_k P_s(i,k) Shift_k(Ψ_s^(h))(i)
```

推荐固定：

- 局部层 `H_local=4`，刻画下一段局部结构；
- 全局层 `H_global=8`，刻画约 40 m 范围内的长程语义；
- `d_successor=128`；
- 每轮 local/global 之间通过 cross-scale residual 交换边界和语义信息。

`Ψ` 同时编码：未来物体/区域语义、路线进程增益、转移不确定性、已验证边比例、粒子配准不确定性与冲突风险。它不是把想象连接当成事实，而是在低置信转移模型上计算风险可见的长期期望。

### 3.9 ghost 反事实长时程价值头

对每个真实 ghost 候选 `j`，在每个粒子内构造一个**只读反事实分支**：

1. 使用图中当前节点到 ghost 的真实相对位置和候选视觉特征；
2. 暂时将该候选作为低置信 proposal 注入局部算子，仅用于本次评分；
3. 读取候选位置的 `Ψ_local、Ψ_global`；
4. 匹配下一认知事件、预测进程增益、未来语义和不确定性；
5. 评分完成立即丢弃临时状态，绝不回写正式地图。

逐粒子候选价值：

```text
Q_j^k = Q_ETP,j
      + w1·instruction_semantic_return_j^k
      + w2·predicted_progress_gain_j^k
      + w3·next_event_match_j^k
      + w4·verified_successor_fraction_j^k
      - w5·transition_entropy_j^k
      - w6·conflict_and_alignment_risk_j^k
```

跨粒子采用风险敏感边际化：

```text
Q_j = E_{π}[Q_j^k] - λ_risk Var_{π}[Q_j^k]
```

将 `Q_j`、后继特征和 provenance 通过 gated FiLM/residual 注入图节点，随后使用 ETP-R1 原有 global graph encoder 与 action head。STOP 节点读取 `finished、remaining、progress uncertainty`，但不读取空间 footprint。

最终仍只能从 `[STOP]+ghost` 中选动作；visited 与 padding 保持原 mask。认知地图没有权限创造候选边。

## 4. 输出与可解释诊断

每个时间步输出：

1. `action_logits`：STOP/ghost 最终决策；
2. `M_world,t`：更新后的 `(37,100,100)` 完整认知地图；
3. `O_t/U_t/C_t`：覆盖、不确定性和冲突；
4. `π_t、W_t`：四个配准粒子的权重和 warp；
5. `p_phase、remaining`：执行进程；
6. `F/B/P`：物理可达性、指令路线流和规划转移；
7. `Ψ_local/Ψ_global`：短程与长程后继语义；
8. 每个 ghost 的即时 ETP 分数、长期增益、风险惩罚和最终分数。

这些量必须进入训练日志，才能判断收益来自真实纠错、几何重配准还是模型单纯学会依赖额外参数。

## 5. 训练监督与总损失

### 5.1 在线地图更新使用网格损失，不使用 JSON 文本损失

LLM-Grid 生成器仍采用：

```text
instruction → JSON token CE → rasterize → 离线 cache M0
```

MPSH 在线更新器直接优化网格、证据和状态递推：

```text
visual/topological prefix + M0 → M_t → masked grid loss
```

禁止在线执行 `M_t → JSON → 文本 CE`。它会离散化局部几何，无法表达覆盖、不确定性、冲突和转移证据。JSON 仅保留为生成器训练格式与离线审计格式。

### 5.2 地图 target

当前认知地图 GT 是路径条件稀疏 GT，其零值可能表示未知，不能全部当负样本。训练时构造三态监督：

```text
observed-positive
observed-valid-negative
unobserved/unknown
```

用训练 simulator 的 depth + scene semantics 离线构造累计可见区域 `Ω_t` 和有效语义 target；该 oracle 数据只进入 `target_*` 字段，policy forward 不接收。可复用 `etp_llm/llm_grid_oracle_cache.py` 中的投影几何生成训练标签。

因果 target 为：

```text
Y_t = Ω_t · Y_scene + (1-Ω_t) · stopgrad(M_{t-1})
```

稀疏认知 GT 的正值额外作为 route-support 正监督；没有可靠 full-scene negative 时使用 PU 学习，不能把全图零值做普通 BCE。

### 5.3 完整损失

```text
L_total = L_nav
        + λ_ev   L_evidence
        + λ_map  L_map
        + λ_ret  L_retain
        + λ_prov L_provenance
        + λ_aln  L_alignment
        + λ_warp L_warp
        + λ_div  L_particle_diversity
        + λ_tr   L_transition
        + λ_succ L_successor
        + λ_td   L_TD
        + λ_prog L_progress
        + λ_cf   L_counterfactual
        + λ_cal  L_calibration
```

| 损失 | 定义 |
|---|---|
| `L_nav` | 原 SAP/DAgger teacher-action CE |
| `L_evidence` | 37 类视觉多标签 Focal BCE、visibility、coverage 与 precision NLL |
| `L_map` | 仅有效 mask 内的 class-balanced Focal BCE + object/region Dice + mixture NLL |
| `L_retain` | write footprint 外 `M_t` 对 `stopgrad(M_{t-1})` 的 KL |
| `L_provenance` | 未核验、支持、冲突、视觉新增的分类/排序监督 |
| `L_alignment` | 含 null/gap 的事件匹配 CE 或 soft-DTW NLL |
| `L_warp` | 坐标 Huber、起点锚定、尺度/Jacobian/曲率约束 |
| `L_particle_diversity` | 防止四个粒子初始化即坍缩，同时不鼓励无意义发散 |
| `L_transition` | 八方向 feasibility Beta NLL + route-flow CE |
| `L_successor` | 对未来折扣语义占用、进程增益和后续真实边的回归/对比损失 |
| `L_TD` | `Ψ = Φ + γPΨ` 的一致性残差 |
| `L_progress` | 5 phase + off-route + finished CE，remaining SmoothL1，软单调约束 |
| `L_counterfactual` | teacher ghost 排序、future geodesic progress 与 hard-negative ranking |
| `L_calibration` | 语义、配准和转移不确定性的 Brier/NLL/ECE surrogate |

初始权重建议：

```text
λ_nav=1.0
λ_ev=0.20, λ_map=0.30, λ_ret=0.05, λ_prov=0.10
λ_aln=0.15, λ_warp=0.05, λ_div=0.02
λ_tr=0.15, λ_succ=0.15, λ_td=0.05
λ_prog=0.10, λ_cf=0.10, λ_cal=0.05
```

所有 loss 按有效 prefix、有效像素或有效边归一化，不能按 episode 总长度裸累加。训练日志记录各 loss 的梯度范数；若量级差异过大，使用 GradNorm/uncertainty weighting 调整，但完整架构不因此关闭任何模块。

## 6. 训练 pipeline

以下阶段是完整网络的优化流程，不是逐步添加架构。MPSH 的全部模块从结构化预训练开始即实例化并参与最终目标。

### 6.1 数据与 cache 准备

固定：

- LLM 初始先验：现有 `llm-grid-r2r-rxr-r1p5-direction5-s2-tagfree` cache；
- 认知地图 GT：现有 `gt.legacy.r1p5.direction5.v1` / blurred 版本；
- 预训练基础权重：`pretrained/r2r_rxr_ce/mlm.sap_habitat_depth/store2/model_step_367500.pt`；
- category schema、坐标版本、cache manifest 和 split。

为完整模型新增 causal sequence 数据。每个样本是 expert/policy trajectory 的有序 prefix，包含：

```text
instruction
M0 + route metadata
截至 t 的 visited nodes 与真实执行边
每步新增 RGB/Depth/panorama features
node abs_xz / type / age / obs_count / new_evidence_mask
训练专用 Ω_t / semantic target / alignment target
phase / remaining / future discounted semantics / teacher ghost
```

严禁把完整未来 graph 或 suffix observation 放入输入。训练 target 统一使用 `target_*` 命名，并与 forward 输入 schema 分离。

数据增强直接覆盖最终系统最关键的错误模式：

- 认知地图旋转、尺度、平移和局部平滑形变；
- 地标删除、类别替换、重复物体和区域边界扰动；
- 路线方向噪声、转移 barrier 变化；
- 视觉漏检、低光/遮挡、坐标噪声；
- DAgger 偏航、回退和 off-route prefix。

### 6.2 完整架构结构化预训练

初始化：

```text
ETP-R1 公共语言/视觉/图权重
+ 现有 LLM-Grid MapEncoder 可迁移权重
+ 全部 MPSH 新模块
```

每个 batch 直接运行完整递推：

```text
M0 → 4 粒子初始化
→ 逐步视觉事件与 soft-DTW 对齐
→ 粒子语义后验更新
→ 真实边写入双尺度转移证据
→ 进程估计
→ Bellman 后继迭代
→ ghost 反事实评分
→ 每个 prefix 的地图、状态与动作联合损失
```

使用 8～12 个高层步的 truncated BPTT：到边界时只 detach 状态梯度，不重置状态值。完整 trajectory 可通过连续 chunk 顺序 replay。

预训练任务组合：

1. 保留现有 MLM；
2. 保留 SAP，但动作 head 使用完整 MPSH 输出；
3. dense causal map revision；
4. alignment/warp recovery；
5. transition feasibility 与 route-flow；
6. successor semantic/TD prediction；
7. progress/off-route/finished；
8. teacher ghost counterfactual ranking。

优化器建议：

| 参数组 | 学习率建议 |
|---|---:|
| MPSH 新模块 | `2e-4` |
| MapEncoder、graph fusion、global encoder 顶层 | `2e-5` |
| 语言/视觉底层 | 冻结或 `1e-6` |

冻结底层只为保护已有视觉语言表示；多假设配准、后验更新、双尺度算子、进程头与 ghost 读出从第一步共同训练。采用 bf16/混合精度、gradient checkpointing 和按粒子并行以控制显存。

现有 `scripts/submit/llm-grid-try5-pretrain.sh` 的静态 MLM+SAP 数据流不足以训练上述递推，需新增独立 launcher，例如：

```text
scripts/submit/llm-grid-mpsh-pretrain.sh
scripts/submit/llm-grid-mpsh-dagger.sh
```

并使用独立输出目录：

```text
pretrained/r2r_rxr_ce/llm_grid_mpsh_full_v1/
```

### 6.3 完整架构 DAgger

DAgger 必须加载上一步完整 checkpoint，不得退回只含公共导航权重的 baseline 权重。

每个 rollout step：

```text
1. 从 cache 读取/复用本 episode 的 M0
2. 更新 ETP 拓扑图
3. 当前真实新观测更新视觉事件与 4 个配准粒子
4. visited-only 写入 4 个语义后验
5. 已执行真实边更新 local/global feasibility
6. 预测 phase / remaining / off-route / finished
7. 更新双尺度 route-flow 与后继特征
8. 为全部 ghost 建立只读反事实分支并评分
9. 输出 STOP/ghost 分布，执行 DAgger 混合动作
10. train 环境计算全部深监督；val/test 不创建 oracle target
```

状态生命周期：

- 在 rollout 创建 GraphMap 时为每个 env 初始化 `MPSHState`；
- 每步 `update_graph` 后、navigation forward 前推进状态；
- `_pause_envs` 时与 `gmaps/cognitive_maps` 同索引 pop/reorder；
- episode 结束完全清空；
- TBPTT detach 不能改变数值状态。

DAgger 采用双学习率：MPSH/决策顶层 `1e-5～2e-5`，旧 ETP 主干为其 `0.1×`；RGB/Depth backbone 与离线 LLM 生成器保持冻结。完整网络在 DAgger 中始终启用，不采用先关闭多假设或后继算子的过渡实验。

checkpoint 选择以 `val_unseen` 导航主指标为准，同时监控后验校准、粒子熵与长程 ghost 排序；不能仅按训练地图 loss 选模型。

### 6.4 可选 GRPO

若在 DAgger 后继续 GRPO，必须保存有序原始视觉证据和真实边事件，并在 update 时重演 `S_0→...→S_t`。当前只缓存 detached map tokens 的 replay 无法端到端训练配准、updater 和 successor operator，因此不能直接复用现实现宣称“全模型 RL”。

## 7. checkpoint 完整迁移

当前预训练与 DAgger 的键空间不一致是实际风险：预训练 `map_encoder.*` 对应在线 `net.map_encoder.*`；预训练 Try5 fusion 与在线 `net.vln_bert.*` 也缺少可靠显式映射。新方案必须建立唯一 canonical checkpoint converter。

要求：

1. 统一移除 `module.` 等 wrapper 前缀；
2. 显式映射 map encoder、graph fusion、MPSH 各模块；
3. 保存 `architecture=mpsh`、source、cache key、category schema、coordinate version；
4. 关键模块缺键直接报错，不能宽泛 `strict=False`；
5. 加载后逐键比较 shape、checksum 或 `max_abs_diff`；
6. 固定 batch 比较预训练末端与 DAgger step 0 的地图、粒子、进程、后继特征和动作 logits；
7. 参数必须挂在 `policy.net`，保证 DAgger checkpoint 自动保存；episode state 则由 trainer 管理，不能注册为模型参数/buffer。

完整 checkpoint 至少包含：

```text
prior_map_encoder
visual_evidence_encoder
cognitive_event_extractor
multi_hypothesis_aligner
particle_semantic_updater
local_transition_operator
global_transition_operator
route_progress_head
successor_solver
ghost_counterfactual_head
ETP language/visual/graph/action backbone
```

## 9. 主实验：先验证完整最终形态

第一轮研究结论只比较完整系统与必要基线，不拆模块：

| 方法 | 目的 |
|---|---|
| ETP-R1 | 无认知地图基线 |
| Try5 + 静态 LLM-Grid | 当前静态融合基线 |
| **完整 MPSH + LLM-Grid** | 本方案主实验 |
| 完整 MPSH + GT map | 地图先验质量上限，仅作 oracle 参照 |

至少 3 个随机种子，以 R2R `val_unseen` 为主，报告 SR、SPL、NE、nDTW、SDTW、OSR、路径长度和 STOP precision/recall。

同时验证完整机制是否真的工作：

- observed 区域 object/region F1、IoU、Brier/ECE；
- unobserved 区域对初始先验的 retention；
- 冲突纠正率与视觉新增召回率；
- 配准误差、粒子 oracle gap、粒子熵；
- phase accuracy、off-route/finished F1、remaining MAE；
- coarse-exit prediction、successor feature error；
- 长距离分叉处 teacher ghost top-1/top-k；
- 正确、旋转/缩放、局部语义错误、连接阻断四类认知地图 stress test。

完整方案有效的核心判据：

1. 多 seed 的 `val_unseen` 同时稳定优于 ETP-R1 与静态 Try5；
2. 错误先验下表现为局部纠错、重配准或不确定性上升，而不是整图擦除；
3. 长距离语义分叉的 ghost 选择显著改善；
4. 只在 PriorGT oracle 上提升、不在 LLM-Grid 上提升，不算成功。

## 10. 确认有效后的消融顺序

完整主实验确认有效后，再围绕科学问题进行细致消融：

### 10.1 认知地图进化

1. 静态地图 vs 持久化后验；
2. visited-only write vs 禁止视觉写入；
3. 无 uncertainty/conflict/provenance；
4. JSON 文本 loss vs masked grid loss；
5. 仅正样本 vs visibility-aware 有效负样本；
6. graph→map 语义更新关闭。

### 10.2 配准与多假设

1. `K=1` vs `K=4`；
2. 无 warp、刚性 warp、平滑非刚性 warp；
3. hard winner vs 风险敏感粒子边际化；
4. 无 null/gap；
5. 几何-only、语义-only、语义+边界+拓扑；
6. ghost 是否错误参与粒子更新。

### 10.3 后继算子与长时程价值

1. 仅 10×10 vs 20×20+10×10；
2. `H_global=1/4/8/12`；
3. 仅语义后验、仅转移校正、二者完整握手；
4. feasibility 与 route-flow 合并 vs 分解；
5. 禁止真实边校正；
6. 无 successor/TD target；
7. 简单当前格采样 vs ghost 反事实 Bellman 读出；
8. ghost proposal 错误写入 vs 只读。

### 10.4 进程对决策的作用

1. 无进程任务；
2. 仅辅助 loss；
3. 送入 ghost head；
4. 同时送入 ghost 与 STOP head；
5. soft-DTW 进程、神经进程和两者联合。

### 10.5 严格因果对照

1. 替换/打乱未来 suffix，当前输出必须不变；
2. ghost/STOP 写入必须严格为零；
3. 无新证据时状态必须不变；
4. 同一旧 visited 观测不得重复增加 evidence；
5. pause/reorder/reset 后各 episode 状态不得串线；
6. coarse-token 内短边不能被误计为一次全局 Bellman shift。

## 11. 最终研究主张

如果完整系统成立，最有价值的结论不是“又加了一个地图 attention”，而是：

> 指令想象的认知网格可以被表示为带多假设空间配准、语义不确定性和长程转移结构的动态先验；视觉拓扑图用真实观测和已执行边在线修正这一先验；修正后的双尺度后继表征再为真实 frontier 提供风险可见的远期价值，从而形成双向、持久、因果的地图联合演化。

该形态完整覆盖四个目标：

1. 视觉拓扑图在线更新认知地图；
2. 明确区分视觉支持、未见想象、认知冲突和视觉新增；
3. 认知地图为 ghost 提供真正的长时程价值，而非单格静态特征；
4. 认知地图与 visited 图联合估计执行进程，并直接参与 ghost 与 STOP 决策。
