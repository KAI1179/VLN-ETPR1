# S4 Online Refiner 新实验结果分析

## 1. 运行状态

- 训练已完成 30,000 iter；日志无 CUDA、NaN 或进程异常。
- IL loss 在约 0.38–0.47 间波动，末期为 0.467；训练没有明显发散，但后期已基本平台期。
- 每 200 iter 耗时约 8–16 秒，速度波动较大，主要是环境 rollout 开销。

## 3. 与 Try5 基线比较

- Try5 历史最佳记录：SR 65.42、SPL 55.25。
- 新模型最佳已测 SR 64.76（约低 0.66 个百分点）；SPL 55.27（基本持平，约高 0.02）。
- 相比 Try5 同为 9k 的结果（SR 62.32、SPL 52.27），新模型 SR +2.44、SPL +3.00；但这不是严格同一训练随机状态，不能单独作为最终结论。
- 新模型 OSR/NE 改善较明显，但路径长度和步数偏长，收益更多体现为“能到达附近”，而不是更高效地停在目标。

## 4. 离线地图质量

冻结 Refiner 在不接入导航决策时，对 P0 的整图 IoU 在 100×100、50×50、10×10 三种分辨率和 seen/unseen 两个 split 均有提升；例如 val-unseen 综合语义 IoU：

- 100×100：5.08% → 11.26%
- 50×50：5.99% → 15.67%
- 10×10：13.80% → 26.24%

因此 Refiner 确实改善了地图本身；导航端收益未完全兑现，主要问题更可能在地图融合后对 Try5 决策分布的适配（包括停止、路径效率和拓扑节点排序），而不是 Refiner 完全不起作用。

## 5. 结论

当前训练是健康的，且离线地图修正有效；但在线导航尚未超过 Try5 的 SR 上限。建议将 15k（SR 最优）和 28k（SPL 最优）作为候选 checkpoint，同时补测 30k，并优先分析“步数增加/停止决策”和拓扑节点排序，而不是继续盲目延长训练。
