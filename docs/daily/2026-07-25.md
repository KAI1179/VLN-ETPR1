# 2026-07-25：起点 oracle evidence 因果 screen 结果

## 今日结论

Seed 42、2 epochs 的 observation-bounded oracle evidence screen 在共同评价集合上**方向性通过**：`val_unseen` 的 matched condition 同时显著超过 null、within-scene shuffle 与 global shuffle 的 overall Cell F1 和 Raster IoU，并在 pooled unobserved cells 上保持更高 F1/IoU。这说明模型确实利用了与当前起点匹配的可见语义，而不只是依赖 instruction 或任意 scene-level semantic inventory。

但这还不是最终因果结论，也不足以进入 Try5 navigation：

- 只有一个 training seed；预设结论仍要求至少三个 paired training seeds。
- unobserved 增益由 precision 主导：matched recall 为 0.1336，低于 within-scene 的 0.1690，不能表述为“恢复了更多未知 cell”。
- 当前 scene-cluster bootstrap 只覆盖 episode-macro F1/IoU、类别、方向与 schema validity，不覆盖 pooled observed/unobserved 或 union 指标；后两者目前只有描述性 effect size。
- evaluator 的 `prediction_evidence_union` 是“当前 condition 的 prediction ∪ recipient prompt semantics”，不是此前文档所指的独立 legacy predictor union。Matched 虽超过这个 deterministic post-processing baseline，但严格的 legacy-union contract 尚未完成。
- Remote launcher 只给 within-scene condition 加了 common-population 参数，导致原始 `val_seen` 的 matched/null/global 使用 778 条，within-scene 使用 769 条。本地已对四个 condition 统一重评为 769/1,839；数值影响很小，但原始 seen 表格不能直接作为严格 paired comparison。

因此当前最准确的结论是：**matched 起点语义提高了 unseen layout prediction 的选择性与精度，single-seed causal screen 成功；是否稳定改善 completion recall 和跨 seed 泛化仍待验证。**

Matched 相对 null/within/global：

- Overall F1：+0.3175 / +0.1182 / +0.2223；
- Overall IoU：+0.1954 / +0.0749 / +0.1405；
- Unobserved F1：+0.1243 / +0.0297 / +0.0903；
- Unobserved IoU：+0.0663 / +0.0166 / +0.0490。

Interpretation：

- Null 输出为有效 empty prediction，因此其 union 等于 evidence-only baseline（F1/IoU 0.1975/0.1095）。Null 是强烈的 input-format distribution shift，主要用于确认模型不能在无 evidence 时工作；within/global shuffle 是更有信息量的 controls。
- Within-scene 的 unobserved recall 高于 matched，但 precision 只有 matched 的约 57%；matched 的优势主要是 instruction 与当前观测匹配后减少 false positives。
- Global 仍有非零性能，说明 instruction 和非匹配 semantic inventory 仍提供 generic category/layout prior；matched 对它的大幅优势才体现 observation identity 的价值。
- Matched output 还超过同一 prediction 的 deterministic `prediction∪evidence` 后处理：F1 +0.0448、IoU +0.0375。直接 union 会加入大量与 route target 无关的可见语义 false positives；LLM 的筛选优于无条件复制。

<details>
<summary>指标语义与仍未完成的统计验证</summary>

- Overall Cell F1/Raster IoU 是 episode-macro；observed/unobserved、evidence/union、mentioned/unmentioned 与 category presence 是 pooled counts，不能直接相减或互相加权还原。
- Cell count 是 category channel × grid cell，不是 unique 2-D locations。
- Evidence baseline 只使用实际写入 prompt 的 semantic grid；`structure`、`other`、`free-space` 已排除，free/observed geometry 不被偷算作 semantic prediction。
- Recipient evidence 始终用于 observed/unobserved partition 和 deterministic baseline，即使 prediction 来自 shuffled donor condition；这是共同 causal frame。
- Diagnostics 的分布统计使用全部 expected episodes，correlation 只使用 schema-valid predictions。
- 当前 evaluator 验证 evidence key/manifest hash，但不验证 assignment kind/seed/hash；本轮已人工检查四组 cache manifests 均固定同一 checkpoint、evidence manifests、seed 42、scale 2、3,072/4,096 token limits 与相同 system-prompt hash。
- 现有 bootstrap 不含 pooled unobserved 与 union sufficient statistics，因此不能给这两个预设 completion criteria 正式 CI。

## RGB-D perception 决策状态

07/24 已完成 segmentation 与 detection 的候选、理由和论文证据记录；本日结果没有改变该表示决策：

1. 主路径仍是 closed-vocabulary、efficient RGB-D semantic segmentation；
2. detector-generated instance masks 是 latency fallback；
3. raw boxes 只作速度上界与 box-to-grid distortion ablation；
4. object segmentation 与 panoramic region classification 分开；
5. DFormer/DFormerv2、ESANet、YOLOE masks 与 YOLO-World boxes 的具体选择继续留待 paired local benchmark。

Oracle screen 的成功说明“起点可见语义是否值得做”已有正向证据，但还不能说明哪个 deployable perception model 最合适，也不能把 GT semantic 上界误写成 RGB-D 系统结果。

## 决策与下一步

1. 暂不启动 Try5 navigation，也不把单 seed 结果写成最终 causal claim。
2. 修正 remote launcher，使 matched/null/within/global 都显式使用同一个 hash-pinned common population。
3. 扩展 paired scene-cluster bootstrap，加入 pooled unobserved 与 condition-specific union sufficient statistics，并明确 legacy-union baseline contract。
4. 用至少三个 paired training seeds 复现 matched 与 controls；重点报告 unobserved precision/recall，而不是只报告 F1。
5. 保留本轮成功与失败 artifacts；原 within-scene failure 作为 strict exclusion design 的消融证据。
6. 等 paired-seed predictor 结论后，再决定 DFormer/DFormerv2、ESANet、YOLOE masks 或 detector box ablation 的实际 benchmark 顺序。
