## 机制解读与决定

1. **`nav4-fusion` 没有通过 matched screen。** fixed 和 selected 对比都
   远低于 `+0.005` SPL 门槛，而且 SR/OSR 明确下降。按预注册不再
   开启两个新 training seeds，也不因 nDTW 一项上升而改写主 gate。
2. **这不是“GRPO 整体失败”。** `nav4` control 相对同一 DAgger
   aggregate 的 SR 约 `+0.010875`、SPL 约 `+0.000598`，说明只调整标准
   navigation blocks 可以提高 success，但 SPL 收益很小。额外训练 Try5
   的单向 `graph_map_attention` 反而消耗了这个 SR/OSR 收益。
3. **fusion 更像在以 reachability 换轨迹紧凑性。** 它的 steps 和 path
   length 更短、nDTW 更高，但 final distance 和 collisions 更高，SR、OSR
   更低且 SDTW 没有可区分提升。stop-error 的无条件比例下降与 OSR
   分母同时下降，不足以单独宣称 stopping 机制改善。
4. **“group 太同质导致 zero advantage”已被强烈反驳。** 所有 10 个
   aggregates 的 zero-reward-variance fraction 都是 0；每个 8-rollout
   group 平均有 `7.970–7.992` 个不同 reward 和 `7.969–7.991` 条不同
   graph-node action trajectories。这证明 advantage signal 存在，但不证明
   outcome reward 对 map decision 的 credit assignment 良好。
5. **“没有优化信号”也不成立，但优化不平衡仍值得保留为诊断。**
   四个 `nav4` modules 都有 finite nonzero gradients，且它们的 tensors 全部
   改变；但 `global_encoder` norm 约 `12.26–15.60`，明显高于 SAP
   `2.05–2.36` 与两个 text/query blocks `0.013–0.026`，全局 clip ratio
   仅 `0.139–0.166`。这是可能的 gradient-budget 问题，但当前 negative
   matched gate 不支持继续扩展 fusion 训练。

结论只适用于 ordinary LLM-Grid + Try5 的单向 graph-to-map attention 适配；
`map_encoder` 与 predictor 都是 frozen，因此不能将本结果扩大为“所有地图融合或
可微地图编码器都无效”。另外，当前只有一个 training seed；11-scene
cluster bootstrap 只刻画该 seed 的 evaluation cohort 不确定性，不替代多 seed
复现。treatment 早于新 population fingerprint instrumentation，虽与 control
使用同一 dataset/cache 交集语义，但不宣称 treatment 一侧有相同的有序 population
密码学证明。

### 修正与冻结契约

早期 CPU freeze 均在写 artifact 前主动停止：第一次是加入完全相同指令去重，第二次是修正跨场景逐轨迹随机 paraphrase 后才匹配长度的问题，第三次是加入 backend fingerprint、联合匹配与 immutable/evaluation contract。停止时仍在读取/序列化本地 raster，没有保留过期 manifest。

跨场景控制现在对两个 slot 联合求解：先最小化最大 raw input token 差，再最小化两 slot 总差，最后用稳定 SHA-256 排序打破平局。最终公平性使用两组完全相同的 role/header，且以实际 chat-template 渲染后的 K2/K3 prompt 与 sequence token 差复核；任何样本群的最大绝对差超过 32 都使 freeze 显式失败。

冻结输出同时保留便捷路径和 `outputs/llm_grid_primary_curriculum/by-sha256/<SHA>/` 下的只读 immutable manifest/evaluation plan。提交脚本要求调用者显式传入该 SHA，run 路径也含 SHA 前 12 位，因此排队的三个实验组不会因共享 mutable 文件改变语料。

评估使用现有 `llm_grid_navigation_cache` 的 deterministic generation（`do_sample=False`）与 `llm_grid_eval`。当前两个工具都显式限定 `R2R`，所以冻结的评价范围只有 R2R `val_seen/val_unseen`；RxR 仍是训练 augmentation，不虚构不存在的 RxR cache manifest。主 endpoint 是 `val_unseen/category_aware_raster_iou` 的 episode macro：同场景相对 K1 与跨场景的点估计都必须至少 `+0.005`，只有预注册 confirmatory 的同场景减跨场景 contrast 额外要求 10,000 次 paired scene bootstrap 的 95% 下界大于 0。`direction_vector_cosine` 分别在每个 contrast 两组都 support=1 的交集 episode 上比较并报告交集分母，不要求三组 support mask 完全相同；object/region F1 容忍下降 0.01，`schema_valid` 不容忍下降。缺失或非法预测保留 evaluator 给出的零指标并进入 episode 分母，同时单独报告 missing/invalid 数量与比例；只有跨实验组 episode 顺序/总体不一致才中止比较。比较 CLI 还会核对 CSV `cache_model_key`、三组训练 metrics 的 condition 与 manifest/corpus/tokenizer/system SHA、run 内复制的 manifest/evaluation plan，以及 R2R 两个 split cache manifest 的 checkpoint 路径与 generation contract。

## GRPO 剩余机制判别计划

当前证据已经排除“8 条 rollout 基本相同而没有 advantage signal”，也排除
“只要解冻 Try5 单向 `graph_map_attention` 就能恢复收益”。尚未区分的主要解释是：

1. 最终 DAgger 已把当前 sampler 可访问的提升空间大多吸收；
2. sampler 中仍有足够的好轨迹，但当前 scalar trajectory reward 的排序或逐步
   credit assignment 没有把它转化为 policy gain。

不先启动另一个 500-iteration arm。第一阶段在完全相同的 `_10` 有序 population、
seed、dropout、G=8 sampler 与 trajectory limit 上，对 original ETP-R1 DAgger
和 LLM-Grid DAgger 做 frozen opportunity audit，不更新参数。每个 episode 同时
保存 deployed greedy rollout 与 8 条 stochastic rollouts，并区分：

- `max reward − group mean reward`，即 GRPO group 本身的可用差异；
- 被最大 reward 选中的轨迹相对 greedy 的 SPL/SR/OSR headroom；
- 不考虑当前 reward 排序时，8 条样本中最大 SPL 和 any-success 的 sampler-support
  上界；
- 最大 reward 与最大 SPL 是否选择同一轨迹，以及首个分歧 action、STOP/move
  错误、teacher-action agreement。

先用同一 `val_unseen` episode denominator 重算 original 与 LLM-Grid 各自的
`GRPO−DAgger`，锁定需要解释的 gain gap。若 LLM-Grid 的 max-SPL 上界本身很小，
且 final DAgger 相比事先锁定的中途 DAgger checkpoint 呈现“性能上升、headroom
下降”，支持 post-DAgger saturation；若 max-SPL 仍大但 max-reward 对应的 SPL
很小，优先归因于 scalar reward 排序不对齐；若 max-reward 可访问 headroom 足以
覆盖 gain gap，而训练收益仍很小，则进入 credit/optimizer 分支。

在任何完整新训练前，先对固定 rollout groups 做一次 optimizer audit，确认正
advantage actions 的 `log p_new−log p_old` 为正、empirical surrogate 改善，并核对
KL、clip、各 block gradient 与 checkpoint delta。只有 reward-accessible headroom
充足且 optimizer audit 正常，才允许一个 `nav4` temporal-credit arm：把当前总
reward 精确分解为 telescoping progress rewards 与终点项，逐 decision 使用
return-to-go，但强制每条轨迹的 reward 总和与现有 contract 逐浮点一致。其余
checkpoint、population、seed、G、optimizer、schedule 与 fixed iteration 500
evaluation 不变。机制门槛仍为相对已完成 standard `nav4` 的
`ΔSPL>=+0.005`、`ΔSR>=0`、`ΔOSR>=0`；若还覆盖至少 75% matched gain gap，才视为
完整解释。否则保留 parameterization/generalization 等第三类解释，不强行二分。
