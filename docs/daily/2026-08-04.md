### 冻结选样协议

四个 all-channel 样本均要求 schema valid、prediction/target support 为正且最佳角度为
strict winner。非零角度在该角度组内选择最接近 episode `delta IoU` 中位数的样本；
`0°` control 选择最接近 identity IoU 中位数的样本；距离相同时按 scene/example
字典序决定。

两项 cross-family 图要求 true-start、strict selector winner、selector 与 held-out
分数均为正且 held-out `delta IoU > 0`，再选择最接近该 positive-transfer 子集
`delta IoU` 中位数的样本。因此这两项只能说明“同一旋转有时会跨 object/region
迁移”，不能估计总体成功率。运行前记录的 region→object 候选
`EU6Fwq7SyZv/R2R_val_unseen_1490` 不符合上述中位数代表规则；sealed replay 拒绝后，
按冻结规则纠正为 `x8F5xyUWy9e/R2R_val_unseen_1594`，其 `delta IoU=0.095338`，
对应子集的中位数为 `0.095165`。

## LLM-Grid-Oracle-t0 source-matched pretraining 预注册

## 目标与停止条件

下一项判别实验只检验当前 matched LLM-Grid-Oracle-t0 cognitive map 在
source-matched Try5 pretraining 后是否具有导航价值。先完成严格的
`pretrain/mixed` evidence、navigation-ready cache、共享 cohort、配对 pretraining
与 DAgger；在 DAgger 决策门前不启动 GRPO，也不启动 YOLOE pipeline。

## 可证伪假设

按当前优先级排列：

1. Oracle map 的 source/pretraining 分布失配是主要瓶颈；source-matched
   pretraining 后，Oracle arm 的配对 DAgger 指标明确优于 ordinary arm。
2. source-matched pretraining 只能恢复 ordinary 水平；observation evidence
   改善 predictor fidelity，但没有提供足够的 route-useful information。
3. Oracle arm 仍较差；单一 raster 中的局部 evidence 覆盖或稀释了
   instruction-only global prior，瓶颈位于表示或 fusion。
4. 历史 ordinary 与 Oracle 的训练 population 不同造成部分表观差异；严格共享
   pretraining 与 DAgger cohort 后差异缩小。

## t=0 observation identity 与无泄漏约束

pretraining observation 只由原始 annotation 的 `scan`、`path[0]` 与 `heading`
确定。`path[0]` 通过既有 cached `ConnectivityEntry.map_for` 得到 Habitat world
position；`heading` 转为与 Habitat 坐标约定一致的 unit yaw quaternion。去重键只含
scene、start position 与 start rotation，因此同一起点/朝向的 sibling instructions
共享一次渲染。

observation collection 不读取 instruction、`path[1:]`、goal、teacher action、
connectivity edges、future observation 或 route-relevant target。完整 path 和
instruction 只在既有 predictor/cache item 构造路径中使用，不进入 evidence producer。
