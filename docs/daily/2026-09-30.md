## 栅格信息量：跨 episode 置换测试（patch 0024）

历史 try5（LLM-Grid 2，iter28000）training-free 通道消融：Full 65.42 / No-object 65.80 / No-region 65.31 / Joint-zero 64.06 / Direction-zero 65.25 / All-three-zero 64.17。object 与 region 可互相替代，只有两者都置零才掉约 1.4。置零是训练中从未出现的输入，无法区分"栅格有 episode 特异信息"与"全零输入的分布偏移代价"。

新增 `make_raster_donor_cache.py` + `eval_raster_donor.sh`：每个 episode 保留自己的元数据，只把栅格换成别的 episode 的 LLM 栅格（cross_scene / within_scene 且排除同 trajectory_id），派生为新的 cache key，评测零代码改动。判定：cross_scene ≈ control → 栅格无 episode 特异信息，1.4 是 OOD 代价；cross_scene ≈ Joint-zero → 真实信息。

核查：map encoder 无位置编码、mask 全真，`GraphMapCrossAttention` 为普通 cross-attention，因此策略对 10×10 块置换严格不变（CPU 随机权重数值验证：输出最大差 2e-7，平移 3 像素为 0.19）。`gmap_pos_fts`（`graph_utils.get_pos_fts`）以当前位姿为参照，是自我中心坐标。

### 结果（历史 try5 iter28000，同一 harness，val_unseen 1839）

control 65.09 / within_scene 65.20 / cross_scene 66.01。配对分析（11 场景 bootstrap）：cross_scene − control SR +0.92，CI [+0.11, +1.86]，McNemar p=0.057，增益主要在可达性（N→S 27 vs S→N 17，OSR +0.71 CI [+0.20, +1.31]）；within_scene − control SR +0.11，CI [−0.90, +1.06]，p=0.91。

结论：该策略不使用栅格中任何 episode 或场景特异信息，换成别场景的 LLM 栅格不掉分（若有差异反而略高）。图中 Joint-zero 掉的约 1.4 为全零输入的分布外代价。cross_scene 的 +0.92 仅一个 donor seed、p 边缘，待 SEED=1/2 复现。R16-DAgger 的判定改用 control vs cross_scene，不用 metadata_only。

复现：cross_scene 三个 donor seed SR 66.01 / 65.91 / 65.96（control 65.09，within_scene 65.20），SPL 55.40 / 55.40 / 55.42，OSR 71.07 / 70.69 / 71.23。增益 +0.82～+0.92，对 donor 抽样稳定。eval 对相同输入是确定性的（R8 已证），因此这是系统性效应：本场景一致的 LLM 栅格（自己的或同场景他人的）比别场景的栅格低约 0.9 SR。within_scene ≈ control 说明起作用的不是"与本指令匹配"，而是"与本场景匹配"的内容；推测为基于内容的 cross-attention 把与视觉上相符的类别当作线索，但因无布局信息而无法利用，形成轻微干扰（待验证）。
