## LLM-Grid-Oracle-t0 导航上界与 evidence-only 消融

### 目的

当前 matched LLM-Grid-Oracle-t0 predictor 在 observation-bounded GT-semantic
evidence 下提高了 predictor-quality Raster IoU，但尚未验证该增益能否转化为
导航 SR/SPL。后续导航实验应同时回答两个问题：

1. 完美的 `t=0` 可见语义能给当前 Try5 导航带来多大收益；
2. 收益来自可靠的局部 observation evidence，还是来自 LLM 对未观测区域的补全。

这里的“上界”只表示 **`t=0` perception/evidence 上界诊断**，不是完整 cognitive
map 或导航系统上界；LLM 输出仍可能不准确。

### 对照组

| cognitive-map input | 含义 |
|---|---|
| ordinary LLM-Grid | 当前 instruction-only LLM-Grid 导航基线 |
| evidence-only reconstructed map | 直接使用 `t=0` observed/free/visible GT-semantic 重建图，不使用 LLM completion；衡量可靠局部 evidence 本身的贡献 |
| matched LLM-Grid-Oracle-t0 | 使用与当前 episode 场景/起点匹配的 observation-bounded GT-semantic evidence 生成 LLM-Grid；衡量 LLM 能否在局部 evidence 之上提供有用补全 |
| PriorGT | 完整 GT cognitive-map 导航参考上界 |

关键解释：

- matched Oracle-t0 `>` evidence-only：LLM completion 提供了额外导航信息；
- evidence-only `>` matched Oracle-t0：LLM completion 破坏或稀释了可靠局部信息；
- matched Oracle-t0 `>` ordinary LLM-Grid：改进 RGB-D perception/evidence 路径可能有实际收益；
- matched Oracle-t0 `≈` ordinary、但 PriorGT 明显更高：瓶颈更可能在 predictor
  或表示，而不是 GT cognitive map 本身无用；
- 各组均接近：需要进一步检查 map encoder/导航策略是否能利用地图质量差异。

### 训练顺序

第一阶段不从头重做 pretraining。先让 ordinary、evidence-only 和 matched
Oracle-t0 共用同一个现有 Try5 pretrained checkpoint，并分别重新进行匹配的
DAgger finetuning；固定初始化、训练步数、seed、checkpoint 选择、cache 缺失
处理和评估分母。这样可以用较低成本隔离 cognitive-map source 的增量价值，并
避免把 source 差异和 pretraining 差异混在一起。

仅替换 cache 直接评估现有 DAgger policy 可作为更便宜的兼容性检查，但属于
out-of-distribution cache swap，不能作为上界结论。

如果第一阶段出现明确增益，或结果接近但怀疑共享 pretraining 限制了新地图的
利用，再进行 source-matched pretraining，并从相同上游初始化、相同 schedule
分别完成 pretraining + DAgger。该阶段才用于估计各 source 在充分适配后的可达
上界。GRPO 暂后置，先用 DAgger 判断方向。

### 前置检查

- 确认 ordinary、evidence-only、matched Oracle-t0 在 navigation `train`、
  `val_seen`、`val_unseen` 上均有 navigation-ready cache；只有 `val_*`
  prediction 时不能完成匹配 DAgger。
- evidence-only map 必须满足 Try5 map contract；缺少的 direction/trajectory
  metadata 不能从 GT route 偷取，应使用各组共享且可部署的 metadata contract，
  或显式修改候选定义。
- 使用 SR/SPL 作为主要结论，保留 paired episode 结果、scene-cluster
  bootstrap 和完全一致的 missing-cache 零分处理。
- GT 选择的旋转角只用于 predictor diagnosis，不得进入本导航实验。
