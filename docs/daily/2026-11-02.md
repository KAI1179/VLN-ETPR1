### 栅格诊断与结果

- namespace 为 `gt.graph.r1p5.direction5.v1`。GT 与预测 layout 走同一写入器，`render_from_layout` 不访问任何 graph/node/object 的 `gt` 字段。
- 初始直接填满区域框，抽样 IoU 约 0.2；原因是 V1 legacy 只复制路径周围的正方形邻域。新增显式 `GraphLayout.route_points_start` 和 1.5 m 半径，GT target 填入所选楼层的稠密路径；预测 layout 必须自行提供预测/在线估计的路径采样点，省略该字段时仍为整框渲染。该接口属于未来 M5/M3 所需额外几何输出，不能在部署时暗读 GT。
- 全部 `val_unseen` 1839 条均有 legacy 对照：类别通道占据 IoU 均值 **0.936855**，中位数 **0.948029**，P10/P90 **0.865060/0.990196**，最小/最大 **0.628571/1.0**；置信度加权 IoU 均值 **0.944349**。`range_y`、`start_position`、`start_direction_vector`、`direction_vectors` 四项元数据在 **1839/1839 完全一致**。
- 最差例 `TbHJrupSAjP/761`：图栅格 176 个非零通道格、legacy 280 个，前者全部包含于后者。缺失为未进入的 circulation 62、living/social space 32、free-space 10；主要是图按设计排除未提及且未进入的区域，以及欧氏 1.5 m 选物体与方形栅格邻域的差异，不是坐标错位。
- `val_seen` 全部 778 条：IoU 均值 **0.939311**，中位数 **0.952970**，P10/P90 **0.865764/0.995314**；加权均值 **0.946467**；778/778 元数据完全一致、对照缺失 0。逐 episode 指标保存在对应 namespace 下的 `render_report_<split>.json`。
- train 全部 10786 条：IoU 均值 **0.931676**，中位数 **0.945783**，P10/P90 **0.854808/0.992933**；加权均值 **0.939731**；10786/10786 元数据完全一致、对照缺失 0。
- M5 采用任务书要求的 start frame，扩展 ADR 0001 旧的 level-local 输出选择；最终 V1 栅格仍为 level-local。任意旋转后区域需 OBB；V1 boxes 兼容格式只能存包围 AABB，因此旋转预测以 raster 为准，M5 的无损目标用 `GraphLayout`。

### 配准与检查

- 配准 NPZ 保存所有原始 GT 点的 `path_node_id/progress/path_xz`，另保存 selected-level mask/index、稠密 route polyline、anchor 与 route ID。进度严格为零起始 `order/n_route`，goal 不是 1。
- 在线查询投影到稠密 route polyline，避免弯路上欧氏最近 anchor 的错误；同坐标的多次访问默认选第一次，调用者可用上一帧的 selected-level path index 打破等距离歧义。hint 不覆盖空间上更近的分支；原楼层外的 GT 点投影到选定楼层，另有 mask 可供 M2 排除。
- `val_unseen` 配准覆盖 1839 条、68124 个完整稠密点，其中 selected-level 64641 点。全部 selected-level GT 点的带 hint lookup 往返错误 **0**，不带 hint 的此 split 实测错误也为 **0**；这不代表任意在线交叉路径都无需历史信息。
- `val_seen` 配准覆盖 778 条、30934 个完整稠密点，其中 selected-level 30211 点；带/不带 hint 的 GT 往返错误均为 **0**。
- train 配准覆盖 **10786 条、414558 个完整稠密点**，其中 selected-level **400932 点**；带 hint 的全量 GT 往返错误 **0**。不带 hint 时，18 个 episode 共 45 个重访点被确定性地归到较早的 route occurrence，证实 M2 在线查标签应维护历史索引。审计脚本已修复这类非零计数的 NumPy 整数 JSON 序列化问题，并重跑全 train 审计通过。
- 自动测试覆盖两区域/门/转弯构图、起点坐标旋转、V1 路径裁剪、无 GT layout 渲染、弯路最近 anchor 陷阱、重访/重复点、楼层外映射及无 pickle 保存。已运行 42 个相关测试（含原有 bbox/direction/coordinate 测试），全部通过；新代码及测试通过 ruff 和 ty。
- 原有 V1 `cached_cognitive_map_to_tensors` 对均匀抽取的 20 个 val_unseen 新缓存实测 **20/20** 通过，37×100×100 grid、5×2 direction5 与起点字段正常且有限值。环境中直接先 import torch 会选中旧系统 libstdc++，因此该抽检显式设置 conda 环境 `lib` 到 `LD_LIBRARY_PATH`，未修改依赖或消费者。
- 最终完整性检查：三个 split 共 **13403 套 graph/registration/boxes/raster** 全部存在并实际解析在本副本的 `data_v2/` 内；所有 split 的 legacy 对照缺失均为 0、元数据完全匹配、带 hint 配准往返错误均为 0。汇总保存在 `data_v2/cogmap_v2/validation.json`，生成数据由 `.gitignore` 排除，代码与本文结果随实验分支提交。
