# 2026-07-24：LLM-Grid 起点观测边界 oracle evidence

## 决策

先做 **observation-bounded oracle evidence** 的因果诊断，不先做可部署但语义较弱的起点 navigability sidecar。该 evidence 只由 `t=0` 语义与深度观测构造，必须受实际视野和遮挡限制，且不得依赖 instruction、goal、GT trajectory、teacher action、connectivity graph、后续观测、sibling paraphrase 或 route-relevant target。Oracle 标签只用于 predictor 诊断上界，不作为导航候选。

保持现有 full-grid target、LLM JSON、navigation-ready `.npz`、Try5 map encoder 和 navigation trainer 不变。先只改变 predictor 输入与 cache generation，并为 evidence、null、within-scene shuffle、global shuffle 生成显式 manifest。评价必须把 observed 与 unobserved cell 分开，并加入 observed-only 与 legacy prediction union observed cells 两个 model-free baseline；复制已给 cell 不算 completion 改善。

该选择延续 [07/23 的 input/target 结论](2026-07-23.md#今日结论)，但不把该假设当作已证实结论。通过标准仍是：matched evidence 相对 null/shuffle 在 paired seeds 上改善 `val_unseen`，且提升必须出现在 unobserved cells 并超过 deterministic union。

## Uncertainty-Aware VLN 论文审查

论文的 Semantic Gaussian Map 在每个 waypoint 从 multi-view RGB-D 在线构建，并把 Gaussian 的 geometric、semantic、appearance uncertainty 作为局部 reliability cue 输入 policy。它没有显式区分 free 与 unknown，也没有输出多个全局 layout hypothesis；variational posterior 最终被压缩为每个 Gaussian 的 scalar standard deviation，appearance uncertainty 则是 Fisher block 的 log-determinant。

因此论文支持“观测证据应携带可见范围与不确定性边界”，但不直接支持把当前 LLM-Grid 改成 Gaussian map、在线 updated cognitive map 或 uncertainty-output predictor。其 uncertainty 没有独立 calibration 评价，ablation 也没有 matched/null/shuffle 或 observed/unobserved completion 分解，不能把新增 scene information 与 map architecture 的收益完全隔离。第一轮只借鉴 observed/unknown 显式表示，不修改 predictor output 或 navigation contract。

论文仓库目前只有标题，未发布实现；不计划在第一轮复现 SAM2 + CLIP + 3D Gaussian optimization。

## 初步代码审查

- 现有 frozen waypoint path 在 environment reset 后、第一次 action 前已经处理 12-view RGB/depth，并可输出最多五个 bearing/distance candidate；但实际 waypoint predictor 当前只使用 depth feature，因此它仍是后续的 deployable geometry control，不是本轮 semantic oracle。
- Habitat helper 可以渲染带 z-buffer 遮挡的 semantic 与 depth frame，但仓库尚无把它们投影到当前 37-channel cognitive-map grid、并同时产生 observed/free/unknown mask 的完整实现。
- `VLNCEEpisodeEntry.iter_from` 会读取 GT trajectory，不得用于 evidence generation。Evidence producer 应直接从 Habitat episode reset 获取起点 pose；scene ID 只可用于 simulator scene selection 和 artifact routing，不得进入 prompt payload。
- full-scene semantic boxes 不受相机遮挡限制；用 fog-of-war 裁剪 box raster 也不能替代 observation-bounded semantic projection。

## 原型与 preflight 结果

- 已实现固定 12 个 yaw、256×256、HFOV 90°、metric depth 0–10 m 的同步 semantic+depth 起点采集；相机保持 episode start pose，不执行 action。Semantic instance 经 MPcat40 object 与 parent region 映射到现有 27+10 channels。
- Artifact 同时保留 start-centered/heading-normalized ego frame 与 level-local/world-aligned target frame；prompt 只使用 target frame，避免把 frame conversion 当成 predictor 能力。Scene ID 只用于加载和路径，不进入 prompt。
- NPZ 严格要求 bool semantic/observed/free、float32 start pose，`allow_pickle=False`；unknown 为 observed complement。Index、manifest、artifact 与 matched/null/within-scene/global assignment 均有 SHA-256，assignment 在 observation 层生成，sibling instructions 共用 donor。
- R2R `val_unseen` 的 50 个 unique start observations 对应 222 个 examples；生成约 1 分 50 秒，50 个 NPZ 共 173,737 bytes，平均 3,475 bytes，存储不是瓶颈。全 split inventory 为 R2R 3,211 observations、RxR 10,574 observations。
- 一个真实 CLI smoke artifact 可严格写入并 reload。50-observation sample 的 target observed cell 占 full target semantic support 的 pooled 64.1%；直接 evidence 对 full target 的 pooled recall 为 43.0%，在 observed target 上 recall 为 67.2%，但 precision 仅 17.1%。低 precision 符合“完整可见环境”与 route-relevant target 不同，不能把 oracle cell 直接复制当作 predictor 结论。
- 原始 per-cell JSON prompt 不可行：222 个 examples 中 189 个超过 1,152 prompt tokens，51 个超过 2,304。改为 exact row-run grammar，并从 prompt semantic labels 移除已由 observed/free geometry 表达的 `structure`、`other`、`free-space` 后，median prompt 为 1,229 tokens，P90 2,049，max 2,580；`max_input_length=3,072` 时 sample 无 prompt truncation，所有 rendered train sequence 也低于 4,096。
- 完整 R2R `val_unseen` 1,839 examples 的 prompt median/P90/max 为 1,246/1,986/2,727 tokens，completion max 1,915；仅 `R2R_val_unseen_51` 的 combined sequence 为 4,118，超过 4,096，选择性丢弃为 1/1,839（0.054%），远低于 training 的 2% fail-fast 上限。Train+RxR 的 authoritative 比例仍由 training manifest preflight 决定。
- 完整 RxR `val_unseen` evidence index 覆盖 11,006 个多语言 episodes，但现有 route-relevant raster fixed corpus 只包含 3,669 个 predictor examples。后者 prompt median/P90/max 为 1,225/2,013/2,800，4,096 sequence budget 会丢弃 172/3,669（4.69%），已超过 2% 上限；其中 prompt 本身无一超过 3,072，主要瓶颈是较长 target JSON。保持 JSON contract 不变，把 screen 调整为 `max_new_tokens=4,096`、`max_sequence_length=5,120`，该 split 只剩 5/3,669（0.136%）超 sequence budget，并继续用 2% guard 检查未知的 train distribution。Control cache generation 同步使用 4,096 new-token ceiling。
- Free 与 region semantic 是独立事实；早期 contract 错误禁止两者重叠，使 smoke free cell 只剩 1–2 个。修正后 sample median free cells 为 16，且保持 `free ⊆ observed`。
- 完整 R2R split 中 observed mask 覆盖 target semantic cells 的 70.2%。实际写入 prompt 的 semantic cells 对 route-relevant target precision/recall 为 16.1%/25.5%；若 evaluator 偷看 artifact 中未写入 prompt 的三个 broad environmental channels，recall 会虚增至 48.2%。因此 model-free evidence/union control 已改为使用显式 `prompt_semantic_grid`。False positives 中 57.9% 来自 region channels，最多为 living/social space、circulation、private room 与 dining/food，继续支持“可见全场景不等于 route-relevant target”，而不是直接复制 evidence。RxR fixed corpus 的对应 observed coverage 为 61.2%，prompt semantic precision/recall 为 18.7%/21.4%，结论一致。

## 已完成实现

## RGB-D 感知替换方案调研

### 结论与理由

- 当前 observation-bounded oracle 的输入是 **GT semantic annotation + metric depth**，不是由 RGB-D 预测语义；它用于检验“起点可见语义证据是否有助于补全”，不是可部署感知模块。可部署版本应把 GT semantic sensor 替换为 RGB-D perception，并保持 depth、pose、observed/free geometry、投影和 LLM contract 不变。
- 现有 projector 需要逐像素对齐的 27 类 object/environment 标签与 10 类 region 标签，最终写入 37×50×50 boolean semantics。Object 与 region 可以在同一像素/网格重叠，因此不能使用单一互斥的 37-way softmax；应采用 object segmentation head 与 panoramic region head。Free/observed/unknown 仍由 depth ray geometry 决定。
- 直接填充 detector box 会把框内背景和遮挡物的 depth 错投影成前景类别；只投影 box center/bottom point 又会使证据过稀。Detection 保留的 instance identity 和 box confidence 在当前 category-first boolean grid 中也会被丢弃，所以 raw boxes 与现有接口不匹配。
- Mask 与 depth 逐像素对齐，可保留可见轮廓、遮挡边界和 stuff/surface semantics。虽然 segmentation 通常更贵，但这里只在 `t=0` 处理 12 个 256×256 yaw views，可用一个 batch 推理并按 unique observation 去重缓存；计算成本可以摊销。
- 1 m/cell raster 会削弱亚像素边界精度的价值，重点应是类别正确性、depth/occlusion 对齐、confidence calibration 和 multi-view consistency，而不是追求最重的 mask decoder。
- 文献没有证明所有任务上 segmentation 必然优于 boxes；ICRA 2019 的直接比较显示两者都能改善 semantic target navigation。但在 ETP-R1 的逐像素 RGB-D 投影接口下，mask-derived semantics 是更少失真的主路径。
- 导航文献说明 semantic-map fidelity 会显著影响下游结果：SemExp 把 predicted segmentation 换为 GT 后，Gibson SPL 从 0.199 提升到 0.457、success 从 0.544 提升到 0.731；SSCNav 中 GT observed segmentation 也把 success/SPL 从 0.271/0.157 提升到 0.438/0.259，并显示错误的 completion 会误导规划，confidence-aware fusion 更可靠。

### 候选与暂定决策

| 角色 | 候选 | 用途 |
|---|---|---|
| accuracy-oriented RGB-D segmentation | DFormer / DFormerv2 | 主要精度候选，直接利用对齐的 RGB 与 depth |
| efficient RGB-D segmentation | ESANet | 主要速度候选，针对室内 RGB-D 与实时推理 |
| detector-to-mask hybrid | YOLOE segmentation、YOLACT | 若 dense segmentation 延迟不合格，用 instance mask 保留可见前景 support |
| heavy accuracy reference | Mask2Former / Mask DINO | 只作为精度参考；其 entity/query contract 与当前 merged grid 不完全匹配 |
| open-vocabulary reference | CAT-Seg、Grounding DINO + EfficientSAM | 适合免训练或扩展词表的 baseline；当前固定 vocabulary 下不预期是首选 |
| raw-box latency ablation | YOLO-World boxes | 只衡量速度上界与 box-to-grid 失真，不作为默认可部署表示 |
| mapping/region reference | 360BEV、Open-Fusion、独立 panoramic region classifier | 验证多视角投影、confidence fusion 与 10 类 region head |

暂定的是**表示与实验方向**，不是具体模型：

1. 主路径采用 closed-vocabulary、efficient RGB-D semantic segmentation；
2. raw detector boxes 只作为 latency/quality ablation；
3. 若 dense segmentation 超出启动延迟预算，优先退到 detector-generated instance masks，而不是直接投影 boxes；
4. object segmentation 与 region classification 分开，所有候选共享相同 depth geometry 和 region control；
5. DFormer、ESANet、YOLOE 中最终选择哪一个，等本地 paired benchmark 后再决定。

### 决策实验

先在现有 50 个 `val_unseen` unique starts 上采集配对 RGB-D 与 oracle semantic frames，固定 12-view pose、depth、vocabulary、region head、projection、grid resolution 和 observed mask，比较 DFormer/DFormerv2、ESANet、YOLOE masks 与 YOLO-World boxes。

主要评价不是通用 image mIoU，而是投影到当前 1 m grid 后的 exact category-cell precision/recall/F1/IoU，并按 object/region 和 category 分解；同时记录 confidence calibration、12-view end-to-end P50/P95 latency、views/s、peak VRAM 与 artifact size。统计按 scene/unique observation 做 paired bootstrap，不能把 sibling episodes 当独立样本。

只有 front end 选择完成后，才进入 expensive LLM evaluation；最终仍要求改善 `val_unseen` unobserved-cell completion，并超过 prediction∪evidence baseline，不能只复制 observed cells。
