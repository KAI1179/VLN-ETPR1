# 2026-08-12

## Feature-fusion 快照 checkpoint smoke

### 目标

验证交付给同事的三个完整 DAgger checkpoint 能否在当前 Try5 代码中脱离历史
pretraining checkpoint 严格加载，并使用各自真实 cognitive-map cache 完成最小前向。
该检查只验证交付完整性与代码兼容性，不比较导航性能。

三个候选使用相同的 Try5 单向 graph-to-map navigation architecture；差异是
cognitive-map source/cache 与训练 checkpoint，而不是三种不同 architecture。

### 契约

- [x] 固定代码基线 `c442132aee771395baab443c3037c6d7c4764c4e`，smoke harness
  位于实验分支 `exp/feature-fusion-smoke`。
- [x] checkpoint 在反序列化前校验大小与 SHA-256。
- [x] checkpoint 顶层字段、iteration、980 个 state tensor、588,583,140 个
  scalar、37 个 map-encoder tensor 与 6 个 Try5 fusion tensor 均严格匹配。
- [x] 仅规范化已知的 `net.module.` DDP 前缀；禁止模糊重命名和静默 fallback。
- [x] 使用显式 modern candidate 配置；`MODEL.pretrained_path` 必须是 Python
  `None`。
- [x] model/checkpoint key、shape、dtype 完全相等后使用 `strict=True`；加载后逐
  tensor 精确相等并检查 floating state 全部 finite。
- [x] 使用三种 cache 都存在的固定样本
  `TbHJrupSAjP/R2R_val_unseen_275`，执行 language、map encoding 与合成三节点
  Try5 navigation forward。
- [x] map token 为 `(1,101,768)`、navigation logits 为 `(1,3)`；visited node
  为 `-inf`、valid nodes finite；重复 eval forward 精确一致。
- [x] with-map 与 no-map valid logits 不同，证明已训练 fusion 在前向中实际生效。
- [x] 不启动 Habitat evaluator、不写 episode/aggregate 评价结果，不加载 optimizer
  或 scheduler。

### 结果

| 候选 | checkpoint | source/cache | 最大 valid-logit map effect | 结果 |
| --- | --- | --- | ---: | --- |
| original PriorGT Try5 | iter27800, `127f7628...672d` | `prior_gt` / `gt.legacy.r1p5.direction5.v1` | 0.266505 | PASS |
| blurred PriorGT Try5 r=1.5 | iter29800, `4103199d...be21` | `prior_gt` / `gt.legacy.r1p5.direction5.blurred.v1` | 0.554111 | PASS |
| LLM-Grid Try5 r=1.5 | iter28000, `4e4ab7be...4f3c` | `llm_grid` / `llm-grid-r2r-rxr-r1p5-direction5-s2-tagfree` | 0.055979 | PASS |

三者都严格加载 980 个 tensor / 588,583,140 个 scalar，并在真实 map cache 上
完成前向。构造阶段由 Transformers 打印“weights newly initialized”是预期现象：
`pretrained_path=None` 先构造随机模型，随后 smoke 对完整 DAgger state 执行严格加载
及逐 tensor 精确核对；因此该提示不表示最终模型存在未加载权重。

### 结论与边界

- 完整 DAgger checkpoint 足以支持首轮 feature-fusion adaptation；推理构造不需要
  缺失的历史 pretraining checkpoint。
- 后续新增 fusion 时，load allowlist 只能包含明确新增的参数；所有旧 tensor，尤其
  43 个 map/fusion tensor，仍须严格匹配。
- 本 smoke 没有跑完整 Habitat episode，不复现 SR/SPL，也不验证全 split cache
  completeness；不能据此比较 PriorGT 与 LLM-Grid 的效果。
