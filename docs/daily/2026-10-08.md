
## KD 方向改为"认知地图只在训练期存在"：dual 模式（patch 0056）

`full` 四个 ckpt 的 val_unseen：2400 50.90 / 4000 47.69 / 8000 42.36 / 12000 41.92（SPL 31.1，OSR−SR 14.9），12000 低于 nomap 55.7；已 scancel。0053 的三处修正都在那条 run 里，代码层面（损失数学 + trainer 接线）再未找到 bug；剩下的是设计层面：效应匹配的目标（教师在 GT 走廊上的 Δ_T）对 52% 命中率的 LLM 图不可达，13k 步不降但梯度一直在推。

论文主张改为：LLM 预测的认知地图只在训练期使用，测试时栅格置零、元数据保留、模块全部在位（= `map_ablation metadata_only`）；地图的作用是训练时桥接语言与视觉。依据：测试时栅格不携带被策略利用的 episode 特异内容（donor 置换 ≈ own）；R7（栅格死、GT 教师 KL）66.7 vs 基线 63 已是该设定下的第一个数据点。

KD 方案 `dual`（并行双监督，不用三级链）：每步学生两次前向——带 LLM 栅格（map 分支）与栅格置零（zero 分支，部署视角，RNG 对齐）；L = CE(zero) + CE(map) + λ_GT[KL(T‖map) + KL(T‖zero)] + λ_LLM·KL(sg[map]‖zero)。map 侧 stop-gradient 防坍塌（否则 map 分支放弃读栅格向 zero 靠拢）；rollout 动作由 zero 分支采样（DAgger 数据分布 = 部署策略）。选并行而非链：两个教师给的是不同知识（GT = 答案，含不可预知部分；LLM 图 = 语言可推的空间先验），链会把学生靠视觉可达的 GT 知识卡在 LLM 分支的瓶颈里；R7 已证明 GT→无图直连有效；DGKD（Son et al. 2021）表明教师+助教并行优于纯链。冻结的历史 try5 不能做助教：donor 测试表明它的决策不读栅格。门控本版去掉：`full` 里 JS 均值 0.04、中位数 0.003，教师决策几乎不随地图变化，门无物可门；留作消融。STOP 因子化留开关，本版关。

消融开关：`dual_gt_kl_on_map_branch` / `dual_gt_kl_on_zero_branch`（链 / 纯并行 / 混合）、`dual_ce_on_map_branch`、`dual_rollout_branch`。评测用 `metadata_only`。命门实验 A：训练期 LLM 栅格活 vs 死，都按 metadata_only 评——正在跑的 `gated`（WZ）每个 ckpt 评 own 与 metadata_only 两次即可回答一半。

**dual 在 WZ 4 卡 × 4 env 下 OOM**（allocated 19.7 / 23.5 GiB，reserved 仅多 0.2 GiB，非碎片）：整段 rollout 的激活图要留到 backward（节点 pano embedding 带梯度跨步），dual 每步多一次带梯度的学生前向，map token 在 forward_navigation 入口就进融合，两个分支的 4 层 x-layer 无法共享。用户要求不降 NUM_ENVS、不拖慢训练、不改方案数值。patch 0058：冻结教师权重以 fp16 存放（`IL.gt_teacher_half`，launcher `TEACHER_HALF=True`），map encoder 与 graph-map 融合这两处 autocast 关闭的 fp32 区域保持 fp32，约省 1.1 GiB/进程，实际释放量写入日志。若仍不足，下一步候选：教师与学生共享冻结 RGB/depth 编码器（0.6 GiB，无数值差异）、仅对 zero 分支 x-layer 做 activation checkpointing（梯度逐位相同，wall-clock 约 +3–5%）。

0058 之后仍在 backward OOM（iter 90，allocated 19.9 GiB），且 15 s/it（云端同配置 2.3 s/it，显存贴顶的 allocator 抖动）。patch 0059：`MODEL.activation_checkpointing`——跨模态 encoder 的 4 层 x-layer 前向只存输入、backward 重算（`torch.utils.checkpoint` 非重入式）。本地验证：输出、参数梯度、输入梯度逐位相同，前向对外部 RNG 的消耗相同（zero 分支的 RNG 对齐仍成立）。仅训练时生效，教师与评测走原前向。launcher `ACT_CKPT=True` 默认开。
