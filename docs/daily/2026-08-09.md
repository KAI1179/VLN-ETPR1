## 竞争解释与可证伪预测

1. **最终 DAgger 后，当前 G=8 sampler 可访问的 headroom 很小。** 若成立，
   LLM-Grid DAgger 的 best-of-8 SPL/any-success 相对 deployed greedy 的提升上界
   本身不足以覆盖 matched gain gap；事先锁定的较早 DAgger anchor 应有更大
   headroom。
2. **sampler 中存在好轨迹，但当前 scalar trajectory reward 排序不对齐。** 若成立，
   max-SPL/any-success 上界较大，而 max-reward 所选轨迹的 SPL/SR headroom 明显较小，
   且 max-reward 与 max-SPL 经常不一致。
3. **reward 可访问 headroom 充足，但 broadcast trajectory advantage 的时间 credit
   太粗。** 若成立，max-reward 轨迹足以覆盖 gain gap、一次 optimizer audit 也能正确
   提高正 advantage actions 概率，但 standard GRPO 仍没有兑现；保持每条轨迹总
   reward 完全不变的 return-to-go arm 应改善 SR/SPL。
4. **optimizer/gradient dynamics 没有把 advantage 转成期望的 policy update。** 若
   成立，固定 rollout group 的一步更新不会使正 advantage actions 的
   `log p_new-log p_old` 为正，或 surrogate/KL/clip/module-delta contract 失败。
5. **original 与 LLM-Grid 的表观 gain gap 含 checkpoint/evaluator/cohort confound。** 若
   成立，在同一 ordered `val_unseen` denominator、预先冻结 endpoint 后，
   difference-in-differences 会显著缩小，剩余机制实验无需解释旧表中的全部差值。

best-of-8 只界定当前 proposal distribution 可访问的机会，不等价于整个 policy class
的全局 headroom；若两个 anchor 的 G=8 headroom 都小，只能判定当前 sampler 对全局
saturation 不充分。

## 条件性 temporal-credit arm 预注册

此 arm 仍然只有在 full classification 进入 optimizer/credit 分支，且上述一步
probe 通过后才允许实现。对 sample `s`、原始 env slot `e` 和高层 action
index `t`，保留现有 1.5m authoritative trajectory reward `R[s,e]` 不变，并定义

`Q[s,e,t] = R[s,e] - (d[s,e,0] - d[s,e,t]) / 6`。

这等价于中间 geodesic-progress rewards `(d_t-d_{t+1})/6` 加一个 terminal
correction；每条轨迹的即时 rewards 严格 telescope 回原 `R`，且 `Q_0=R`。
`d_t` 只是行动前的训练 target，不进入 policy input。不能用 padding 或按最终
长度对齐；只在相同 `(e,t)` 的仍存 G trajectories 之间对 `Q` 标准化，
少于两条有效轨迹或零方差时 residual 为零。

现有 objective 的实际 action weight 受 trajectory length 与 active-env reduction
影响。因此对每条轨迹的 normalized RTG residual 做相同 maintained weights
下的加权去中心，再加回现有 terminal advantage。必须用不等长、多 env
synthetic replay 证明：在 rollout ratio=1 时，arm 与现有 scalar objective 的
整体 policy loss 完全一致，只改变同一轨迹内 actions 的 credit。若 reward-sum、
loss invariance、sampling identity 或 nav4-only parameter membership 任一失败，在
optimizer step 前 fail closed，不启动 full arm。

该干预使用 privileged intermediate geodesic distance。因此若成功，只支持
“temporal/geodesic credit 对此 profile 有帮助”，不证明任意 temporal-credit
estimator 都有效。若不做上述 weighted centering，则同时改变了长度与梯度
scale，不是可接受的机制实验。

### Locked math

对 sample `s`、原始 env slot `e`、该 trajectory 的高层 action index `t`，authoritative
1.5m terminal reward 保持为 `R[s,e]`，行动前 geodesic distance 为 `d[s,e,t]`：

`Q[s,e,t] = R[s,e] - (d[s,e,0] - d[s,e,t]) / 6`。

因此 `Q_0=R`；以 `(d_t-d_{t+1})/6` 为 progress reward，并以
`R-(d_0-d_T)/6` 为 terminal correction 时，每条 trajectory 严格 telescope 回原
reward。`d_t` 通过现有 deterministic env API `current_dist_to_goal(is_train=True)`
在 navigation forward/action sampling 前读取；不把 low-level `PositionTrain` history
错当高层 action 序列。terminal `d_T` 使用 `PositionTrain[-1]`，并要求与同一 env API
在 1e-4 内一致。距离不进入 policy input，不产生新 RNG draw。

只在固定 `(e,t)` 仍 active 的 G trajectories 间标准化 Q；不 padding、不按 final
length 对齐。active count <2 或 exact zero variance 时 residual 为 0。现有 terminal
advantage 记为 `A[s,e]`，normalized Q residual 记为 `Z-A`。maintained objective 对
action 的精确 weight 为：

`w[s,e,t] = 1 / (sample_step_count[s] * active_env_count[s,t])`。

对每条 `(s,e)` 用同一 `w` 加权去中心 residual，再加回 A。这样每条 trajectory
都有 `Σ_t w(A_rtg-A)=0`，所以 rollout ratio=1 时现有 clipped PPO policy loss 与
trajectory contribution 均保持不变，只改变 trajectory 内 action credit。

实现中 terminal A 不由新 helper 以 float64 重算，而是直接接收 historical
`np.mean/np.std` block 已按真实 reward dtype 算出的值。`trajectory` default 分支仍走
原 block 与原 step lookup，完全绕过 temporal helper 与 distance validation。float64
weighted-centering 是 authoritative identity gate；production-shaped G8/E4 regression
显示相同 objective 的 float32 reduction 可合法相差 `2.384185791015625e-7`，因此该
drift 只记录 finite maximum，不再用任意固定阈值误拒合法 rollout。
