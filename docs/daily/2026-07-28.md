## LLM-Grid 起点中心四向注册诊断

### 假设与固定协议

检验 LLM-Grid 绝对坐标上的低 Raster IoU 是否主要来自以已知起点为中心的
逐 episode 基数方向误差。仅回放本地 cache，保持 GT、起点和起始朝向不变；在 scale-2
`37x50x50` 栅格（`1 m/cell`）围绕连续起点 pivot，对 37 通道共享地搜索
`0/90/180/270°`。越出 `50x50` 框的 support 保留为 false positive，无效预测以空栅格留在分母。

不确定性使用 11 个 scene 为 cluster、seed `42`、10,000 次重采样的 paired
scene-cluster bootstrap。四个 GT-选择角度仅是 oracle 上界诊断，不是可部署的选择器，也未传入 navigation。

## LLM-Grid 起点中心跨语义族交叉拟合对照

### 冻结问题与协议

本轮只问两个预注册问题：由一个不相交语义族选择的角度，能否提高另一语义族的
held-out IoU；这种迁移是否在 episode 的真实起点 pivot 上强于几何上合理的对照 pivot。
沿用本地 cache key
`llm-grid-r2r-rxr-r1p5-direction5-s2-tagfree-epoch-2`、R2R
`val_unseen` 和 GT cognitive-map namespace
`gt.legacy.r1p5.direction5.v1`。运行 commit 为
`9ee2dfcbaf6da452620bf81d99588f9d04e413c1`；固定总体为 1,839 个不重复
episode、11 个 scene、1,830 个 schema-valid 和 9 个 invalid-or-missing，后者以空预测保留在完整分母。

语义族固定为 object 通道 `[0, 27)` 与 region 通道 `[27, 37)`，分别执行
`object→region` 和 `region→object` 交叉拟合。三个连续 pivot 是真实 scale-2
起点、map center `(25.0, 25.0)`，以及 seed `43` 的 scene 内一对一 shuffled
start；角度顺序固定为 `0/90/180/270°`，平局按声明顺序保留 identity。推断使用同一个
paired scene-cluster bootstrap multiplicity matrix，以 11 个 scene 为 cluster、seed
`42`、10,000 次重采样、episode-macro 权重和 2.5/97.5 百分位区间。

### 验证与结果

独立 artifact validator 验证了 7 个固定产物及其 hash，并逐项确认 1,839 个 identity、
11 个 scene、22,068 个 angle row、11,034 个 cross-fit row、1,839 个 pivot
assignment，以及角度/pivot/direction membership、support 分解、配对算术、有限值、
bootstrap 输入和 literal gate decision。

| endpoint | mean held-out `delta_iou` | 95% scene-cluster CI |
| --- | ---: | ---: |
| true start `object→region` | 0.033631 | [0.028280, 0.039238] |
| true start `region→object` | 0.041313 | [0.036857, 0.045414] |
| true start symmetric | 0.037472 | [0.032780, 0.042123] |
| map center symmetric | 0.000532 | [0.000000, 0.001077] |
| shuffled start symmetric | 0.005129 | [0.002798, 0.007162] |
| true start − map center | 0.036940 | [0.032119, 0.041642] |
| true start − shuffled start | 0.032343 | [0.028061, 0.037573] |

true-start symmetric 的 leave-one-scene-out episode-macro range 为
`[0.035973, 0.039000]`。各 pivot 和两个方向的 selector/held-out
`predicted_support_empty` 率均为 `9/1839 = 0.4894%`，对应保留在分母中的 9 个空预测；
`target_support_empty` 与 `union_empty` 率均为 0。按 `0/90/180/270°` 顺序，选中角度计数为：

| pivot | `object→region` | `region→object` |
| --- | --- | --- |
| true start | 756 / 478 / 239 / 366 | 895 / 418 / 207 / 319 |
| map center | 1817 / 15 / 3 / 4 | 1819 / 12 / 3 / 5 |
| shuffled start | 1559 / 133 / 38 / 109 | 1581 / 125 / 38 / 95 |

其中 identity 数量包含 identity-first 平局和 9 个 invalid 空 selector；因此 map-center
与 shuffled-start 的大量 `0°` 不能解释为可部署角度预测。

### 决策、限制与下一步

五项冻结门槛全部通过：

1. true-start symmetric 均值 `0.037472 >= 0.01`；
2. 其 CI 下界 `0.032780 > 0`；
3. 两个 directional 均值 `0.033631` 和 `0.041313` 均大于 0；
4. true start − map center 的 CI 下界 `0.032119 > 0`；
5. true start − shuffled start 的 CI 下界 `0.028061 > 0`。

故 literal decision 为 **GO**：这支持不相交语义通道间共享的、真实起点中心的基数角
alignment 证据，不是此前同一 target 上选择并评分的 all-channel oracle 证据。
每个方向仍由 GT target raster cells 在 selector 语义族上选择角度，所以该结果不是
target-free，也不是可部署性能；任何 outcome 都不授权 navigation training 或使用
GT 选择角度。该 GO 唯一授权的下一步是设计 target-free 的四路旋转 hypothesis
selector 或 aggregator。
