## Step 0 取证（`scripts/distill/check_pretrained_map_loading.py`）

- `try-5-r1p5_step_387500.pt`：fusion 六个张量全在初始化尺度（in_proj 33.95、out_proj 15.36、residual 15.35），三个 bias
  精确为零；map encoder 的 `category_projection` 与 CLIP 初始化最大差 0.000000，LayerNorm 6/6 为 1.0，bias 17/18 为零。
  **该预训练从未训练地图通路**；教师的读图能力全部来自 DAgger。
- `model_step_460000.pt`：fusion bias 非零、residual 13.73；`category_projection` 偏离 CLIP 0.069，LayerNorm 0/6 在初始值。
  **LLM-Grid 线的预训练确实训练了地图通路。** 两条线的差异原因待查。
- 历史 loader 从未把 `map_encoder.*` 和 `bert.global_encoder.graph_map_attention.*` 装进在线策略（HF 报告 not used）；
  补丁 0001 修复并逐张量校验，0006 修正校验器 key 前缀。387500/460000 的 map encoder 都能严格加载。
- HF `from_pretrained` 的 `_fast_init` 在 `__init__` 之后对未加载子模块重新初始化为 N(0, 0.02)，覆盖了
  `vilmodel_cmt.py:871` 的清零。全新模型 residual 范数 15.34–15.36；教师、蒸馏学生、S4 的 DAgger checkpoint 也都在
  15.32–15.36。**在线策略的 Try5 fusion 从未零初始化**，DAgger 也几乎没改变其尺度。

## 决策

- 放弃基于 387500 的 `z_loader`/`loader` 变体（加载的是未训练权重）。
- R7（460000 初始化，`load_pretrained_map_modules True`）是第一个带预训练地图通路进入 DAgger 的学生；
  与历史 LLM-Grid 2 DAgger（65.42，地图通路从零）对比即可回答"地图预训练是否有用"。
  判据：前 1400 iter `student_ce` 均值明显低于原 run 的 1.09（如 < 0.95）说明地图通路在第 0 步就起作用。
- 待验证假设：随机残差投影在第 0 步注入与图嵌入同量级的扰动，促使策略学会压制地图；可用"`from_pretrained`
  之后再清零"的 flag 做对照。
