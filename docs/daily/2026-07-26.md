# 2026-07-26：R2R-only LLM-Grid checkpoint sweep 对照

## 今日结论

R2R-only epoch 1–10 的完整 predictor evaluation 已成功结束。所有 epoch
都覆盖固定的 `val_seen=778`、`val_unseen=1,839` 条 episode，
`missing=0`、`excluded=0`；无效 JSON/schema 输出仍留在 denominator 中按空预测
计分。因此本轮可以完成 07/24 计划的 R2R-only 与 R2R+RxR-EN 对照。

结果不支持“加入 RxR-EN 改善 unseen-house 泛化”：

- R2R+RxR-EN 最佳 `val_unseen` Raster IoU 为 epoch 2 的 `0.135701`；
  R2R-only 最佳值为 epoch 7 的 `0.133635`。按 scene 配对 bootstrap 后，
  两者差值仅 `+0.002065`，95% CI `[-0.00973, +0.01508]`。
- epoch 10 的 R2R+RxR-EN 相对 R2R-only 在 `val_seen` 上提高
  `+0.07993` Raster IoU，95% CI `[+0.05024, +0.11090]`；但
  `val_unseen` 差值为 `-0.00275`，95% CI `[-0.01185, +0.00526]`。
- Mixed 模型的 seen–unseen IoU gap 从 epoch 1 的约 `0.026` 增至
  epoch 9 的约 `0.168`；R2R-only epoch 9 gap 约 `0.064`。更多数据主要增强
  已见 house 的拟合，没有缓解 scene overfitting。

这与数据覆盖完全一致：RxR train 的 59 个 scene 是 R2R train 61 个 scene
的严格子集，没有引入任何新环境；它与 R2R `val_seen` 的 53 个 scene 中
52 个重叠，与 11 个 `val_unseen` scene 中 0 个重叠。本实验实际检验的是
“在相同 houses 上增加约 1.96 万条英文 route/instruction supervision”，
不是增加环境多样性。

## category F1 sanity check

R2R-only epoch 1/2/5/10 的 `val_unseen` episode-macro combined category F1
分别为 `0.6642 / 0.6643 / 0.6151 / 0.6598`；predict-every-category
baseline 已达到 `0.5482`。Epoch 10 的 object/region F1 为
`0.670/0.667`，但与 Raster IoU 的 episode correlation 仅
`-0.006/0.097`。

Mentioned category F1 明显较高：epoch 10 unseen 的 mentioned/unmentioned
object F1 为 `0.869/0.629`，region F1 为 `0.929/0.533`；但对应 pooled
spatial IoU 只有约 `0.112/0.121`。因此 category F1 能说明模型大致预测了
“有什么”，仍有次级诊断价值；它不能说明“在哪里”，也不适合作为主要
predictor-quality metric。主指标继续使用 Raster IoU/Cell F1，并同时报告
schema validity 与 IoU tail。

## 解释边界与决策

本轮是两个完整 training line 的观察性比较，不是只改变 RxR 数据的严格
ablation。R2R-only 使用历史 user-prompt contract、10,726 个 examples 与
53,630 optimizer steps；mixed 使用 tag-free contract、30,422 个 retained
examples 与 38,030 steps，effective batch、sequence budget、distributed
optimization 和 RNG 控制也不同。Inference system prompt、1,024-token
input 与 4,096-token decode budget 已匹配，但不能把全部差值因果归因于
RxR。

本轮可支持的结论为：

> 在相同训练 houses 上加入英文 RxR route/instruction supervision，
> 显著增强 seen-house 拟合，但没有可测量地改善 R2R unseen-house spatial
> generalization，也没有缓解 scene overfitting。

因此不因本轮结果提前选择 segmentation model；07/24 记录的
efficient RGB-D semantic segmentation 主路径、instance-mask latency
fallback 与 raw-box ablation 候选保持不变，具体模型仍留待 paired local
benchmark 决定。

## 面向汇报的 category-wise 与定性诊断

为避免在汇报中继续堆叠 checkpoint curve，本轮只新增一个 category-wise
摘要图、三条固定定性样本和一个 observation-evidence 最终对照图；完整数值
另存为 CSV/JSON。分析对象固定为 mixed R2R+RxR-EN epoch 2 的
R2R `val_unseen=1,839`；其中 1,830 条 raw prediction 可严格解析，9 条
schema-invalid 按空预测保留在 denominator。

Category-wise 计算区分两个问题：

- `presence F1`：逐 episode 判断某 category 是否在预测/目标中出现，再在
  1,839 条 episode 上 pooled；
- `pooled category-cell IoU`：对同一 category 的 `(episode,row,col)` cell
  计算 pooled IoU。它不是 checkpoint curve 中的 episode-macro Raster IoU。

[Category presence vs spatial IoU](../images/llm_grid_presentation/category_presence_vs_spatial_iou.png)
只展示至少出现在 5 个 target scene 的 category，并从汇报图中去掉
`void/structure/other/free-space` 四个 broad channels；完整 CSV 仍保留全部
37 个 channel。代表性结果如下：

| Category | Presence F1 | Spatial IoU | Target scenes |
|---|---:|---:|---:|
| door | 0.960 | 0.055 | 9 |
| cabinet | 0.758 | 0.033 | 10 |
| table | 0.725 | 0.017 | 11 |
| chair | 0.622 | 0.018 | 10 |
| circulation | 0.952 | 0.134 | 10 |
| work/study | 0.197 | 0.010 | 5 |
| other/miscellaneous | 0.070 | 0.032 | 6 |

Broad channels 的 presence/spatial 分别为
`structure=0.998/0.190`、`other=0.997/0.220`、
`free-space=0.991/0.092`。因此整体 spatial score 会受到大面积环境 mask
影响；对常见离散物体，模型经常知道“有什么”，但基本没有学会可靠的
位置与范围。低 presence + 低 IoU（如 toilet、sink、towel）则同时包含
category selection 与 placement 两类失败。

三条 ordinary LLM-Grid 定性图统一使用 GT、epoch 2、epoch 10 三列以及
共同 crop/坐标轴，避免重复 GT 与不同 crop 造成误读：

- [median](../images/llm_grid_presentation/qualitative/median.png)：
  `R2R_val_unseen_1824`，epoch 2 IoU/category F1
  `0.125/0.621`，epoch 10 为 `0.073/0.516`；
- [最大 category–spatial gap](../images/llm_grid_presentation/qualitative/category_spatial_gap.png)：
  `R2R_val_unseen_690`，epoch 2 为 `0.006/0.929`，直接展示
  category 基本正确但布局整体错位；
- [support-rich failure](../images/llm_grid_presentation/qualitative/support_rich_failure.png)：
  在 epoch 2 schema-valid 的最低 IoU ties 中按 target cell 最多再按 ID
  确定，得到 `R2R_val_unseen_139`。epoch 2/10 IoU 都为 `0`，但 category
  F1 仍为 `0.690/0.667`，进一步说明 category F1 不能替代空间指标。

## GT target、t=0 evidence 与 Oracle raw prediction 最终对照

[最终对照图](../images/llm_grid_presentation/oracle_t0_gt_evidence_prediction.png)
固定使用非挑优的代表 episode `R2R_val_unseen_1633`：它是在 schema-valid
且至少有 20 个 unobserved target category-cells 的 episode 中，最接近
overall/unobserved 联合中位数的样本。图中直接对齐 evaluator 的
`37×50×50` 表示：

1. 完整 route-relevant GT target；
2. 实际序列化进 prompt 的 `t=0` observation-bounded oracle evidence；
3. raw LLM-Grid-Oracle prediction；
4. observed mask 外的 TP/FP/FN/category-substitution。

该例 overall IoU 为 `0.1898`，evidence-only IoU 为 `0.1608`；但
unobserved IoU/precision/recall 仅为 `0.0430/0.0645/0.1143`
（unobserved target support `35` category-cells）。图中可见 predictor
确实把地图延伸到 observed strip 之外，但延伸部分仍以 FP/FN 为主。
这与 matched-control 全量统计一致：GT semantics 的 `t=0` observation
能提供局部增益，但目前没有证据表明它带来了强的 unseen-space completion。

后续视觉对齐复核确认底层坐标 frame 没有平移：该例 evidence start 与
GT route start 仅相差 `1.36e-5 m`，小范围 shift sweep 也在零平移取得最高
IoU。原图的 cyan contour 因 `imshow` 与 `contour` 的 cell-center 约定不同，
显示上偏了半格，现已统一到 `(row+0.5, col+0.5)`；GT route 也仅为汇报显示
snap 到所在 coarse cell 的中心，没有对数据施加固定平移。图中同时加入了
user instruction。

图中为了可读性隐藏 broad channels；中间列现在标注与可见内容一致的
displayed-category IoU `0.2177`，并在页脚保留全部 37 channels 的
evidence-only IoU `0.1608`。中间列使用 `prompt_semantic_grid`，没有偷用
artifact 中被过滤的 `structure/other/free-space`，第三列也没有使用
`prediction ∪ evidence` 后处理。
