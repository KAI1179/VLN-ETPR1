# 2026-07-26：R2R-only LLM-Grid checkpoint sweep 对照

## 今日结论

R2R-only epoch 1–10 的完整 predictor evaluation 已成功结束。所有 epoch
都覆盖固定的 `val_seen=778`、`val_unseen=1,839` 条 episode，
`missing=0`、`excluded=0`；无效 JSON/schema 输出仍留在 denominator 中按空预测
计分。因此本轮可以完成 07/24 计划的 R2R-only 与 R2R+RxR-EN 对照。

结果不支持“加入 RxR-EN 改善 unseen-house 泛化”：

- R2R+RxR-EN 最佳 `val_unseen` Raster IoU 为 epoch 2 的 `0.135701`；
  R2R-only 最佳值为 epoch 7 的 `0.133635`。按 scene 配对 bootstrap 后，
  两者差值仅 `+0.002065`，95% CI `[-0.00973, +0.01508]`。
- epoch 10 的 R2R+RxR-EN 相对 R2R-only 在 `val_seen` 上提高
  `+0.07993` Raster IoU，95% CI `[+0.05024, +0.11090]`；但
  `val_unseen` 差值为 `-0.00275`，95% CI `[-0.01185, +0.00526]`。
- Mixed 模型的 seen–unseen IoU gap 从 epoch 1 的约 `0.026` 增至
  epoch 9 的约 `0.168`；R2R-only epoch 9 gap 约 `0.064`。更多数据主要增强
  已见 house 的拟合，没有缓解 scene overfitting。

这与数据覆盖完全一致：RxR train 的 59 个 scene 是 R2R train 61 个 scene
的严格子集，没有引入任何新环境；它与 R2R `val_seen` 的 53 个 scene 中
52 个重叠，与 11 个 `val_unseen` scene 中 0 个重叠。本实验实际检验的是
“在相同 houses 上增加约 1.96 万条英文 route/instruction supervision”，
不是增加环境多样性。

## category F1 sanity check

R2R-only epoch 1/2/5/10 的 `val_unseen` episode-macro combined category F1
分别为 `0.6642 / 0.6643 / 0.6151 / 0.6598`；predict-every-category
baseline 已达到 `0.5482`。Epoch 10 的 object/region F1 为
`0.670/0.667`，但与 Raster IoU 的 episode correlation 仅
`-0.006/0.097`。

Mentioned category F1 明显较高：epoch 10 unseen 的 mentioned/unmentioned
object F1 为 `0.869/0.629`，region F1 为 `0.929/0.533`；但对应 pooled
spatial IoU 只有约 `0.112/0.121`。因此 category F1 能说明模型大致预测了
“有什么”，仍有次级诊断价值；它不能说明“在哪里”，也不适合作为主要
predictor-quality metric。主指标继续使用 Raster IoU/Cell F1，并同时报告
schema validity 与 IoU tail。

## 解释边界与决策

本轮是两个完整 training line 的观察性比较，不是只改变 RxR 数据的严格
ablation。R2R-only 使用历史 user-prompt contract、10,726 个 examples 与
53,630 optimizer steps；mixed 使用 tag-free contract、30,422 个 retained
examples 与 38,030 steps，effective batch、sequence budget、distributed
optimization 和 RNG 控制也不同。Inference system prompt、1,024-token
input 与 4,096-token decode budget 已匹配，但不能把全部差值因果归因于
RxR。

本轮可支持的结论为：

> 在相同训练 houses 上加入英文 RxR route/instruction supervision，
> 显著增强 seen-house 拟合，但没有可测量地改善 R2R unseen-house spatial
> generalization，也没有缓解 scene overfitting。

因此不因本轮结果提前选择 segmentation model；07/24 记录的
efficient RGB-D semantic segmentation 主路径、instance-mask latency
fallback 与 raw-box ablation 候选保持不变，具体模型仍留待 paired local
benchmark 决定。
