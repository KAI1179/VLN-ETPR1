### Frozen integrity 与 leakage contract

experiment-only `SemanticProjectionGeometry` 只暴露：

```text
depth_m
sensor_positions
sensor_rotations_xyzw
sensor_hfov_degrees
target_origin_xz
```

它不暴露 RGB、object/region GT、observed/free masks、sensor yaw/relative pose、
start pose 或 schema metadata；semantic-only target grid 使用 absolute sensor
poses 与 target origin，start pose 不属于该 dataflow。类型必须精确校验 dtype、
shape、C-contiguous、finiteness、depth `[0,10]`、HFOV `90°` 与 unit
quaternions；传入 `RawFrameArrays` 本身必须显式失败，不能用 structural protocol
让 forbidden fields 仍可达。

对每个 observation，构造 schema-valid deterministic poison，并先断言 replacement
确实不同。逐项和联合替换：

```text
object_categories
region_categories
ego_observed_mask
ego_free_mask
target_observed_mask
target_free_mask
```

同时要求 `depth_m`、`sensor_positions`、`sensor_rotations_xyzw`、
`sensor_hfov_degrees` 与 `target_origin_xz` 在 pristine/poisoned inputs 间
byte-identical。以下四路输出必须逐 observation exact-equivalent：

1. accepted current projector + pristine `RawFrameArrays`；
2. current projector + poisoned `RawFrameArrays`；
3. new geometry-only projector + pristine extracted geometry；
4. new geometry-only projector + poisoned-input extracted geometry。

每路都要求 exact `bool`、shape `(27,50,50)`、C-contiguous、
`np.array_equal` 与 C-order bytes 相等；aggregate SHA-256 只用于 report，不能
代替 direct equality。50/50 任一 mismatch 即停止语义解释，先修复
integrity/leakage/projector seam。该证明只排除 semantic/oracle-evidence fields
泄漏；因为保留 `target_origin_xz`，它不证明 target-origin provenance 或
deployability。

### Frozen contributor 与 attribution contract

建立一行对应一个 stored pixel 的 deterministic ledger，至少记录：

```text
observation, scene, view, yaw, row, column, depth state/bin,
GT canonical label, raw NYU40 label, mapped label,
world x/z, target grid row/column, in-bounds
```

world endpoint 与 cell indexing 必须复用 P6 的 exact pixel-centre、pose、
`floor` 与 bounds rules。depth bins 固定为 invalid `0`、`(0,1]`、`(1,2]`、
`(2,4]`、`(4,6]`、`(6,10)` 与 saturated `10`。

对每个 primary FP cell 列举产生该 category-cell 的全部 predicted contributors
及其 GT label；对每个 FN cell 列举全部 GT contributors 及其 raw/mapped
prediction，并按 unanimous abstention、unanimous wrong class 或 mixed 分类。
contributor-derived TP/FP/FN cell sets 必须与 projector 输出在全部 50
observations 上 exact-conserve：

- 每个 FP 必须至少有一个对应 predicted contributor，且该 cell 没有该 category
  的 GT contributor；
- 每个 FN 必须至少有一个对应 GT contributor，且没有 contributor 预测该
  category；
- 不允许 unexplained residual cell。

守恒失败属于 attribution/projector defect；守恒通过后，boolean multi-label
union 不再视为无证据的独立 root cause，只报告它如何把 semantic pixel error
放大为 cell error，或由正确 contributor 挽救同 cell 中的其他错误。不同
categories 在同一 spatial cell 的 multi-hot co-occupancy 不是 destructive
collision。

## Ordinary LLM-Grid GRPO map adaptation 消融预注册

承接 `docs/NOTE.md` 的“微调阶段可训练/冻结的模块”和“基于 LLM 的 pipeline”
记录。本消融只诊断 ordinary LLM-Grid 的 Try5 map path；在机制得到验证前，
不修改、不重跑 matched LLM-Grid-Oracle-t0 实验。

已确认历史 ordinary LLM-Grid GRPO 指标使用 `ckpt.iter450.pth`，该 checkpoint
由 SPL 选择；maintained launcher 中 `iter500 → iter450` 的本地修改没有提交。
因此历史 `iter450` 只作为既有 selected-checkpoint 结果，不作为本消融的无偏
primary endpoint。本消融预注册 `ckpt.iter500.pth` 为 primary endpoint；

secondary diagnosis，禁止使用 `val_unseen` 选择 checkpoint。
