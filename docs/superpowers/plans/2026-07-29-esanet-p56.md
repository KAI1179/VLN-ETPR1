## Preflight and Command

1. require a clean committed benchmark repository and clean detached upstream
   source at the pinned revision;
2. re-audit source, checkpoint, permission, environment-lock, overlay, private
   runtime loader, raw package, mapping, and projector authorities;
3. require the exact copied venv interpreter and complete environment hash;
4. require destination/staging absence;
5. require physical GPU 4 to be idle, 30–80 Celsius, and the only visible CUDA

   require that exact raw PID through the final snapshot; normalize only that

   empty baseline after P5.3 and immediately before the validated raw reader,

## Run and Acceptance

The publisher must:

1. run the P5.3 fresh validator and descriptor-bound P5.4 raw reader;
2. construct/load the model once outside timed inference while recording cold
   start;
3. execute exactly 20 warmups followed by two ordered 50-observation measured
   passes;
4. require deterministic repeated source/mapped label hashes;
5. capture official CUDA snapshots, end-to-end/component timing, and
   absolute/incremental resource state;
6. compute frozen projection, metrics, robustness, and literal gates only
   after inference;
7. create a canonical `RealSuccessfulManifest`, accept it independently in a
   temporary package, and atomically publish;
8. perform a byte-identical fresh-process validation of the published package;
9. print only the endpoint-free validation record.

Any authority, environment, source, schema, determinism, resource, GPU, or
validation mismatch stops before publication. CUDA OOM is fatal and must not
retry a smaller batch. This runner uses the frozen ordinary timed benchmark,
not the aborted-publication wrapper: a contract-minted CUDA OOM propagates as a
fatal error with no package or stdout rather than mislabel pre-run evidence as
post-run evidence. No successful semantic claim is made unless final
publication and fresh validation both pass.
