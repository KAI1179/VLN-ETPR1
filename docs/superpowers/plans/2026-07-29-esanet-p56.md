## Run and Acceptance

The publisher must:

1. run the P5.3 fresh validator and descriptor-bound P5.4 raw reader;
2. construct/load the model once outside timed inference while recording cold
   start;
3. execute exactly 20 warmups followed by two ordered 50-observation measured
   passes;
4. require deterministic repeated source/mapped label hashes;
5. capture official CUDA snapshots, end-to-end/component timing, and
   absolute/incremental resource state;
6. compute frozen projection, metrics, robustness, and literal gates only
   after inference;
7. create a canonical `RealSuccessfulManifest`, accept it independently in a
   temporary package, and atomically publish;
8. perform a byte-identical fresh-process validation of the published package;
9. print only the endpoint-free validation record.

Any authority, environment, source, schema, determinism, resource, GPU, or
validation mismatch stops before publication. CUDA OOM is fatal and must not
retry a smaller batch. The frozen OOM factory requires its archival before/after
CUDA evidence before execution, so this runner must not publish the returned
aborted package: it stops with an error rather than mislabel a pre-run snapshot
as post-run evidence. No successful semantic claim is made unless final
publication and fresh validation both pass.
