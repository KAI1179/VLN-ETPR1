## Goal and Boundary

Run the pinned official ESANet RGB-D segmenter through the already sealed P5.4
benchmark contract. Add only July-29 experiment code, tests, specifications,
and notes. Do not modify the P5.2/P5.3 sealed packages, the P5.4 public
contract, core projector, navigation code, or model code.

The upstream ESANet checkout remains detached and unmodified at revision

## P5.5 Gates

1. **Artifact gate — passed.** Bind the official Drive object, exact byte size,
   CRC32C, archive SHA-256, safe single-member tar structure, checkpoint
   SHA-256, and restricted-load tensor schema.
2. **Environment gate.** Freeze a hash-checked experiment-local dependency
   layer. Do not modify the shared `pyproject.toml`, `uv.lock`, or current
   environment. Attest the base interpreter/distributions and the added files.
3. **Source/import gate.** Reject any preloaded or competing top-level `src`
   package before adding the exact pinned checkout to the child process. Never
   patch or shim upstream files.
4. **Model gate.** Instantiate the exact 40-class dual-ResNet-34 ESANet
   architecture with explicit arguments, load only the restricted
   `state_dict`, and require `strict=True`.
5. **Preprocessing gate.** Freeze RGB ImageNet normalization, millimetre
   `uint16` depth quantization, NYUv2 depth mean/std, invalid-zero restoration,
   and native `256×256` benchmark geometry. Native resolution is an explicit
   deviation from the official `480×640` test resize.
6. **Technical smoke gate.** On one sealed view, verify input/output
   shape/dtype/device/finite values, deterministic repeated source-label hash,
   exact spatial alignment, and successful restricted strict load. Do not
   calculate or display semantic quality.
7. **Benchmark gate.** Only after independent review of gates 1–6, run the
   frozen 20-warmup plus two-pass 50-observation benchmark on one approved GPU.
   Validate and independently audit the no-overwrite result before exposing
   semantic endpoints or a GO/NO-GO decision.

## Frozen Candidate Configuration

- modality: RGB-D;
- source vocabulary: NYUv2 40 classes;
- RGB and depth encoders: ResNet-34;
- encoder block: `NonBottleneck1D`;
- activation: ReLU;
- encoder-decoder fusion: additive;
- context module: pyramid pooling;
- decoder channels: `[512, 256, 128]`;
- decoder blocks: three per stage;
- RGB-depth fusion: `SE-add`;
- upsampling: `learned-3x3-zeropad`;
- final checkpoint loading: no ImageNet initialization;
- benchmark input/logit geometry: native `256×256`;
- inference: `model.eval()` and `torch.inference_mode()`;
- output: 40 finite logits at input resolution.

RGB is converted to `[0,1]` and normalized with mean
`[0.485, 0.456, 0.406]` and standard deviation
`[0.229, 0.224, 0.225]`. Habitat metric depth is converted exactly as
`(depth_m * 1000).astype(uint16)`, then converted to floating point and
normalized with mean `2841.94941272766` and standard deviation
`1417.2594281672277`; pixels whose quantized raw depth is zero are restored to
zero after normalization.

## Verification and Stop Conditions

- focused pytest, Ruff, and ty checks pass;
- upstream checkout remains clean at the pinned revision;
- the base environment and dependency layer are reproducibly attested;
- restricted load and `strict=True` both pass;
- one-view smoke is reviewed without semantic endpoints;
- any source/hash/schema/import/dependency/alignment/determinism mismatch stops
  the run;
- CUDA OOM, unexpected GPU tenancy, or resource-state mismatch aborts without a
  reduced-batch retry.
