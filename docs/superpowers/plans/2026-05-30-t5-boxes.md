# T5-Boxes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train and evaluate a T5 model that maps VLN instructions plus start metadata to structured object/region box JSON.

**Architecture:** Add a new `vlnce_baselines.models.etp_t5` package for T5-Boxes, separate from Imagined. T5-Boxes outputs canonical category-name JSON, converts valid JSON to `RelevantSemanticBoxes`, rasterizes through the existing cognitive-map path, and evaluates category-aware metrics.

**Tech Stack:** Python 3.8, PyTorch, HuggingFace `transformers` T5, Pydantic-style semantic box models already in `prior.bbox`, pytest.

---

### Task 1: Structured Spec, Prompt, Conversion, Artifacts

**Files:**
- Create: `vlnce_baselines/models/etp_t5/__init__.py`
- Create: `vlnce_baselines/models/etp_t5/boxes_schema.py`
- Test: `tests/etp_t5/test_boxes_schema.py`

- [ ] **Step 1: Write failing tests**

Create tests covering:
- `relevant_semantic_boxes_to_spec()` emits separate `objects` and `regions` arrays using canonical category names, without `mentioned` or `confidence`.
- Output entities sort by category name, then x, then z, then area descending.
- Coordinates/extents round to one decimal; rotations round to two decimals.
- `build_t5_boxes_input()` includes `dataset`, `start_position`, `start_direction`, `instruction`; it must not include scene id.
- `parse_t5_boxes_json()` accepts valid JSON and rejects malformed JSON, unknown categories, missing fields, and invalid geometry.
- `spec_to_relevant_semantic_boxes()` derives `mentioned` from instruction/category extraction and converts names back to indexed `LevelSemanticBoxes`.
- `write_prediction_artifact()` writes normalized JSON for valid predictions and raw text plus error for invalid predictions, not both by default.

- [ ] **Step 2: Run tests and verify they fail**

Run: `pytest tests/etp_t5/test_boxes_schema.py -q`

- [ ] **Step 3: Implement schema and conversion**

Implement:
- dataclasses or typed models `ObjectBoxSpec`, `RegionBoxSpec`, `T5BoxesSpec`, `T5BoxesValidationError`
- constants `OBJECT_CATEGORY_TO_ID`, `REGION_CATEGORY_TO_ID`
- `build_t5_boxes_input(dataset_tag, instruction, start_position, start_direction) -> str`
- `relevant_semantic_boxes_to_spec(relevant: RelevantSemanticBoxes) -> T5BoxesSpec`
- `spec_to_relevant_semantic_boxes(spec, instruction, level_idx, reference_path, start_direction_vector, range_y=None, category_extractor=None) -> RelevantSemanticBoxes`
- `parse_t5_boxes_json(text: str) -> T5BoxesSpec`
- `spec_to_json(spec: T5BoxesSpec) -> str`
- `write_prediction_artifact(output_dir, example_id, valid_spec=None, invalid_text=None, error=None) -> None`

Validation rules:
- object categories must be in `MAPPED_OBJECT_NAMES`
- region categories must be in `MAPPED_REGION_NAMES`
- object `center` and `half_extents` are two finite numbers; half extents must be positive
- region `min` and `max` are two finite numbers; max must be greater than min on both axes
- JSON top-level must contain `objects` and `regions` arrays only
